# FreePair v0.143.20261008

## What's new

- **Use the selected NA Chess Hub site throughout an event.** New events inherit the NACH link in Settings. Sign-in, event browsing, roster sync, publishing, public scoreboard links, and private results entry use the selected HTTPS service, including staging or PPE sites. Switching that link takes effect without restarting FreePair; sign in again on the new service rather than carrying a sign-in across sites.
- **Links and logos stay with the event's site.** View Event on NACH, Save Event, the event-card organizer logo, and Share's roster link open the selected site instead of production. Organizer logos are fetched and cached separately for each site, so a test event cannot display a production event's cached logo. When NA Chess Hub supplies its own sharing link, FreePair continues to use the link returned by the service.
- **A clearer live-sharing signal.** After the first successful scoreboard publish, Share becomes bold green and shows a radio-tower icon. It returns to normal while reconnecting or when sharing stops. A fatal sharing failure restores Start Sharing after cleanup; automatic retries still offer Stop.
- **Roster improvements reach every platform.** The recent NA Chess Hub sync fixes now reach macOS and Linux too: newly registered players retain available federation ratings and details, and switching US Chess post-event pairing before a rating refresh no longer discards existing pairing IDs and ratings. These fixes previously shipped to only some platforms.

## Installer

- **All four platforms.** Windows x64, Linux x64, macOS Apple silicon and macOS Intel builds are included.
- **Runtime and engines included.** Installers and portable builds bundle the required .NET runtime and pairing engine.

## Known limitations

- **NA Chess Hub sharing requires internet and an account on the selected service.** Switching between production and a test site signs out the previous local session; sign in separately on the new site. Test and production events are separate.
- **Some discretionary choices can differ from SwissSys.** When a source event does not record why a legal board-order or bye choice was made, FreePair may make a different permitted choice.

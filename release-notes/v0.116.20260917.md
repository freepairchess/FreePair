# FreePair v0.116.20260917

## What's new

- **QR links take less space.** Event and section headers now use one compact QR dropdown instead of several tiny QR buttons, with a clearer QR-style icon and larger scannable codes inside the menu.
- **QR printing is easier to control.** The Print QR Codes dialog lets you choose exactly which available event, pairing, scoreboard, result-entry and optional Wi-Fi codes go onto the one-page sheet.
- **Share links are simpler.** The Share window puts local and NA Chess Hub Live Score Board links side by side, then result entry, with shorter text and per-link browser buttons.
- **Result entry filters sections.** The phone result-entry page can show all sections, only sections missing results, or only sections with complete results.
- **Autosave no longer moves the screen.** Routine save progress stays in the event card's Last saved line instead of opening and closing a banner that shifted the workspace during almost every operation.
- **Event Configuration uses the workspace.** The Event Configuration page stretches like section pages instead of sitting in a narrow centered column.

## Installer

- Windows x64 installer and portable package are published for this release.
- The installer bundles the required .NET desktop runtime and the pairing engines.

## Known limitations

- **Windows-only release.** macOS and Linux remain on the previous all-platform release until the next multi-platform build.
- **Known SwissSys-fidelity trade-offs remain.** The curated comparison suite still carries the established SwissSys-discretionary differences; this release focuses on QR sharing, result-entry filtering and UI stability.

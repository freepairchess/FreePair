# FreePair v0.52

A **Bughouse Pairing** release. Bughouse (team-vs-team) events now run cleanly as
individual-style events whose "players" are the two-person teams, and the results
you publish to NA Chess Hub now list and rank those teams correctly. This build
also makes FreePair's published results file match SwissSys exactly, which fixes
a standings-ordering glitch some online events could hit. Ordinary individual and
team events are unaffected, so upgrading is low-risk and recommended.

## What's new in v0.52

### Bughouse Pairing sections

- **Run a bughouse event as an individual event of teams.** A **Bughouse Pairing
  Section** treats each two-person team as a single competitor: it pairs, scores,
  and ranks the teams like an individual Swiss, with plain board numbers (no team
  sub-board `1.1` / `2.1` labels).
- **Clearer, consistent labels.** The Roster, Standings, Wall Chart, and Pairings
  tabs read **Team Roster / Team Standings / Team Wall Chart / Team Pairing**; the
  name column shows the **Team**, and the members column shows the two players.
  The board pairings show **White Team / Black Team**.
- **No confusing team prompts.** Pairing a Bughouse Pairing section skips the team
  setup dialog and the "teams not ready" check, and the round-1 colour dialog
  hides the "avoid pairing players from the same team" option (it doesn't apply
  when every competitor is already a whole team).
- **Locked, clearly-named type.** The section is labelled **"Bughouse Pairing
  Section"** and becomes read-only once set, so it can't be flipped by accident.
  You can still add and edit the team players.
- **Right action, front and center.** For a team roster that hasn't been converted
  yet, the Pairing Operations menu offers just **"Create a Bughouse Pairing
  Section."**

### Correct online results for these events

- **Publish and print as an individual event.** Publishing to NA Chess Hub and
  printing PDFs now treat a Bughouse Pairing section as individual, so the teams
  are listed and ranked by their game-point totals.
- **Standings order fix.** FreePair's published results file now matches the
  SwissSys format exactly, so a higher-scoring competitor can never appear below
  a lower-scoring one on the results page. This also tightens correctness for
  ordinary individual events whose final order differs from the seeding.

- **Auto-update:** Existing FreePair installs will pick up v0.52 automatically.
  To update now, click "Check for updates" in the Settings tab.

The installer bundles the .NET 10 runtime, the pairing engines, and the
rules-reference document — no additional downloads or configuration required.

## Known limitations

- **Re-publish to refresh online results.** NA Chess Hub keeps a previously
  uploaded results file until an event is re-published. If an event was published
  before this release, publish it again so the corrected standings order takes
  effect.

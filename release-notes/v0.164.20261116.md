# FreePair v0.164.20261116

## What's new

### Event access and NA Chess Hub

- **Clearer ways to open events.** The event menus and dialogs now say "Open" instead of "Re-Open" and name NA Chess Hub directly instead of referring to an "Online Registry" or a "Cloud-Saved" event. Creating an event from a Hub roster and browsing Hub events use the same terminology.
- **NA Chess Hub account is easier to find.** Its toolbar menu now sits immediately left of Settings with the Hub logo. The Online tab in app-wide Settings is named **NA Chess Hub**; the separate per-event Online tab is unchanged.

### Sharing QR codes

- **QR codes have one spacious home.** Choose **View → QR Codes** (the last View menu item) or **Share → QR Codes** to see available pairings, scoreboard and optional venue Wi-Fi codes. Preview a code at full size, copy its link, open it in a browser, add or remove a venue Wi-Fi code, or print a QR sheet.
- **More room in the event toolbar.** The compact QR dropdown is gone; **Print → Print QR Codes** still opens the printable QR sheet.

## Installer

- **All four desktop platforms.** Windows x64, Linux x64, macOS Apple silicon and macOS Intel builds are included.
- **Runtime and pairing engine included.** Installers and portable builds bundle the required .NET runtime and chess pairing engine.

## Known limitations

- **Browser sign-in is separate from FreePair sign-in.** Links open in the computer's default browser and profile. If that profile is signed out of the selected Hub host, the page can appear signed out even when FreePair is signed in; this release does not establish a browser session.
- **Some discretionary choices can differ from SwissSys.** When a source event does not record why a legal board-order or bye choice was made, FreePair may make a different permitted choice.

# FreePair v0.70.20260814

## What's new

### Titled players are seeded correctly in FIDE events

- **Players on the same rating are now ordered by title.** In a
  FIDE-rated section, when two players have identical ratings, the
  titled player is seeded first — GM, then IM, WGM, FM, WIM, CM, WFM,
  WCM, then untitled — before falling back to alphabetical order. This
  is what the FIDE rules require, and FreePair was going straight to
  alphabetical.
- **This decides real boards, not just a list.** In round one nobody has
  a score and nobody is owed a colour, so the seeding order is the only
  thing deciding who plays whom. Two players in the wrong order is a
  different round one, and a different event after that.
- **US Chess sections are untouched.** They break an equal-rating tie
  alphabetically, with no title step, and that is exactly what they
  still do. The behaviour follows the section's own rating type, so a
  dual-rated event gets the FIDE treatment while a club Swiss does not.
- **National and arena titles are shown but not ranked.** NM, SM, LM and
  the arena titles are kept and displayed, but they seed as untitled,
  because the FIDE list does not include them. Giving them a position
  would mean deciding something the rules do not, and that decision
  would change pairings.

### Titles no longer disappear when you save

- **A title you type now survives closing the event.** Setting a
  player's title in the player form worked for the rest of the session
  and was then lost on reopen, silently reverting to whatever the file
  arrived with. It is now written with everything else.
- **This mattered more than it looked.** Now that titles decide seeding
  in FIDE events, a lost title meant the pairing numbers you approved
  before round one were not the numbers you got when you opened the file
  again.

### Titles are visible where you need them

- **Title now appears by default** on the Roster, Pairings, Standings
  and Wall Chart. Something that decides pairings should not be hidden
  behind a column chooser.
- **On the pairing sheet it sits in front of the name** — "GM Smith" —
  rather than taking a column of its own, so nothing is squeezed.
- **Printed standings and wall charts only add the column when it is
  needed.** If nobody in the section is titled, the column is left out
  rather than printing a strip of blanks across an already-wide sheet.

### Clearer prompts before round one

- **The seeding prompt now describes the order it will actually use.**
  It previously said "by rating, then by name" for every section, which
  was simply wrong for FIDE events. Each prompt now names the order its
  own section will apply, and the same is true of the Roster tab's
  restore-defaults confirmation.
- **Re-sorting is now the recommended, pre-selected choice.** Letting
  FreePair number the field from the pairing rules is the intended path,
  so it is the default button and pressing Enter takes it. Keeping the
  current numbers is still available for the case it exists for —
  reproducing a starting list that was assigned elsewhere and has to
  match exactly.

## Installer

- Windows, macOS and Linux builds. Bundles the .NET runtime and both
  pairing engines — nothing to install separately.
- The user guide and the USCF rules reference are installed with the
  app.
- Updates from an earlier version in place; your settings and recent
  events are kept.

## Known limitations

- **Pairing numbers still cannot be renumbered mid-event.** FIDE treats
  the numbers assigned at the start as provisional and expects
  definitive ones once entries close. A player added after the event
  starts takes the next free number rather than the one their rating
  would earn. Pairings are correct either way; it is the numbering on a
  submitted crosstable that a strict reading would question. This is the
  next piece of seeding work.
- **Only FIDE titles affect seeding order.** National titles are
  displayed and stored but seed as untitled, as described above. This is
  deliberate rather than an omission.
- **Files exported by other software may arrive seeded incorrectly.**
  FreePair re-seeds correctly whenever you let it, but it preserves the
  numbers a file arrives with, since on an imported event those may be
  an official starting list that has to be reproduced exactly. If the
  file was produced elsewhere with equal-rated players ordered without
  the title step, choose the re-sort option when prompted before round
  one.
- **Offline rule and help links have been verified on Windows only.** On
  macOS and Linux they are expected to work but have not been confirmed
  on this release.

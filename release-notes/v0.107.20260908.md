# FreePair v0.107.20260908

## What's new

### Messages without wasted space

- **Message history has its own event-level tab.** Select the event name
  in the left sidebar, then open **Messages** to find this window's session
  history. It is an event tab, not a tab inside each section.
- **The empty message row is gone.** Active notices still appear below all
  toolbar buttons, but when none remain, the space goes back to the event
  workspace instead of holding a standalone Messages button.
- **Dismissal points you to the recovery location.** A brief overlay offers
  **Open Messages** and **Close** without reserving another row. **Show again**
  recalls a historical notice without repeating its operation or changing
  tournament data.
- **Recovery preserves your place and edits.** Opening Messages leaves
  focus mode when needed and keeps pending event-form edits. Session history
  remains available after view rebuilds and when no event is open.

## Installer

- **Windows x64 only.** Run `FreePair-win-x64-Setup.exe` to install or
  update. It includes the .NET runtime, both pairing engines and the updated
  user guide, and uses the FreePair logo.
- **Signed as Chessnique LLC.** This release promotes the signed Windows
  build already tried by the developer, without rebuilding its installer or
  application packages. Signing now runs automatically in the build pipeline.
- **macOS and Linux remain on v0.103.20260906.** No new packages for those
  platforms are included.

## Known limitations

- **History lasts for this application-window session.** It is not stored
  in the event file and is cleared when the window closes.
- **Signing does not suppress every security prompt.** SmartScreen
  reputation, antivirus policies and administrator-permission prompts are
  separate from publisher identification.
- **Existing SwissSys pairing differences remain.** Some opponent, bye and
  colour choices differ in specific situations. This release does not change
  the pairing algorithm, and agreement with another program is not a rules
  verdict.

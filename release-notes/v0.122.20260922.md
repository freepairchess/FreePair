# FreePair v0.122.20260922

## What's new

- **TD PINs stay stable for the same event.** Local-network and NACH result-entry PINs are ready immediately and no longer rotate when you stop/start sharing or reconnect. Use **Change PIN** only when you intentionally want a new secret; old local tablet sessions are still revoked on restart.
- **QR menu cleanup.** The toolbar QR menu now uses flat menu-style action rows, hides **Add Venue Wi-Fi QR** once a venue Wi-Fi code already exists, and places **Print QR Codes** above the QR list.
- **QR printing avoids duplicate Wi-Fi prompts.** When the Venue Wi-Fi QR is already in the QR list, the print dialog no longer shows a second Wi-Fi-entry form.

## Installer

- **Windows x64 release.** This is a Windows-only local release; macOS and Linux remain on the previous all-platform release until the next full-platform build.
- **Runtime and engines included.** The Windows installer bundles the required .NET runtime and pairing engines.

## Known limitations

- **PINs are session secrets, not event-file data.** They stay stable while FreePair remains open for the same event, but closing and reopening FreePair may require a fresh PIN.
- **NACH hosted pages still need their matching hosted refresh work.** This release keeps the FreePair-side PIN and QR workflow stable while the hosted page behavior remains governed by the NA Chess Hub deployment.

# FreePair v0.118.20260918

## What's new

- **Quads workflow is smoother.** Quad events can split players into named quad sections, keep teammates apart, and make family-name teams from the quad dialog. Once quad sections are paired, their round count is locked so the created schedule cannot be accidentally reshaped.
- **Scoreboard and QR sharing are clearer.** The toolbar now says Scoreboard, the QR menu sits beside Share, wraps long rows instead of scrolling sideways, and can include a venue Wi-Fi QR code that can be saved in app settings.
- **Share is organized by task.** The Share window has separate Scoreboard sharing, Pairing sharing, and Result entry tabs. QR menu actions open the matching tab, and unavailable NA Chess Hub actions point directly to Online settings.
- **Phone result entry is faster.** Players tap a result and go straight to confirmation. Forfeit options are tucked under Game is forfeited?, forfeits display in red, and the phone page can filter both sections and rounds by missing or complete results.
- **Result-entry audit columns are available on screen.** When local result entry is shared, the Pairings grid can show where a result came from and who entered it, while print and grid-copy output keep those internal audit fields out.
- **Pairing columns are consistent across sections.** Grid and print column choices are app-wide for the event view, support same-columns-for-both-players and mirrored display, and no longer lose player identity/rating columns when saved numeric layouts from older builds are loaded.
- **Settings and event lifecycle are safer.** Settings can be restored to app defaults, Close Event no longer waits on network cleanup, newly created events appear in Open Recent, and non-NACH web imports no longer retain stale NA Chess Hub credentials.

## Installer

- Windows x64 installer and portable package are published for this release.
- The installer bundles the required .NET desktop runtime and the pairing engines.

## Known limitations

- **Windows-only release.** macOS and Linux remain on the previous all-platform release until the next multi-platform build.
- **Known SwissSys-fidelity trade-offs remain.** The curated comparison suite still carries the established SwissSys-discretionary differences; this release focuses on quad workflows, sharing, result entry, display settings, and lifecycle fixes.

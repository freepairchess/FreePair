# FreePair v0.112.20260912

## What's new

### Player database search finds the person you asked for

- **Searching a full name no longer hides the right player.** FreePair asked
  the player database for an exact name match, and only tried a close
  ("fuzzy") match if that came back empty. The database's exact match ignores
  middle names — so searching *David W. Martin* returned every *David Martin*
  and not the one you had spelled out. The more of the name you knew, the
  worse the search performed.
- **Both searches now run, and the closest names come first.** The two result
  lists are merged, duplicates removed, and rows ranked by how much of the
  name you typed they actually account for. A player whose middle initial
  matches sorts above the namesakes who only share a first and last name.
  Searching a plain first and last name behaves exactly as before.
- **The search runs itself when it opens.** You have already typed the name
  into the Add-player form; the search now starts from it straight away
  instead of waiting for a second click. Press **Search** whenever you want a
  different query.
- **Narrow a long list without searching again.** A common surname can return
  forty players or more. The new **Narrow results** box filters the rows
  already on screen — instantly, with no second lookup — and matches any
  column, so a middle initial, a state, or part of an ID all work.

### Make teams from family names

- **Put siblings on the same team in one step.** **Make Teams With Same Family
  Name** places every player who shares a surname onto one team, which is what
  **Avoid pairing teammates** then works from. It is on **Event Operations**
  for the whole event, and on a section's **Roster Update** for just that
  section.
- **See every change before anything happens.** The dialog lists each player
  it would move, the team they have now — shown as *(none)* when they have
  none — and the team they would get. Cancel changes nothing, and the whole
  batch is a single **Undo**.
- **Choose the sections, at event level.** Every section starts ticked; untick
  the ones to leave out. Each row shows its roster size, rounds and whether
  teams affect its pairings at all.
- **Name the teams your way.** The team name is a pattern — `{family}` is
  replaced by the surname, so the default `Team {family}` gives *Team Nguyen*.
  An example beside the box updates as you type.
- **Teams you entered yourself are protected.** **Overwrite current team name**
  is off by default, and players who already have a team are listed separately
  with the team they keep, so you can see them and decide rather than discover
  it later. Tick the box to replace those too.
- **A surname held by one player in a section is left alone**, because there
  is nobody to keep them apart from. For the same reason families are worked
  out within each section: players in different sections never meet over a
  board.
- **A clear warning when it would move real boards.** If a section is already
  paired *and* set to avoid teammates, a separate confirmation explains that
  pairings will differ from the next round on. Rounds already played and
  results already entered are untouched.

### A more usable collapsed sidebar

- **The collapsed section list is readable again.** It was narrow enough to
  show about three characters, which made `U1700` and `U1200` look the same.
  It now opens wide enough for roughly six, and shows as much of each real
  section name as fits.
- **Drag it to whatever width your section names need.** The divider works
  while the sidebar is collapsed as well as expanded, and each state remembers
  its own width, so widening the rail does not disturb the full list you get
  back.
- **Small fix:** the **Search Player DB** button now matches the height of the
  Verify buttons beside it.

## Installer

- **Windows x64 only.** Run `FreePair-win-x64-Setup.exe`. The installer
  includes the .NET runtime, both pairing engines and the updated user guide.
  Keep your normal event backups before updating.
- **Signed as Chessnique LLC.** The local Windows release process signs and
  timestamps the installer and packaged executables before publication.
- **macOS and Linux remain on v0.109.20260910.** This release does not replace
  their existing packages.

## Known limitations

- **Family teams are a roster label, not a team event.** They fill in each
  player's team so that **Avoid pairing teammates** can use it. Turning that
  option on is still your decision, and it cannot be changed once a section
  has paired round 1.
- **Teams are grouped per section.** Two players with the same surname in
  different sections are not made teammates, because they can never be paired
  against each other.
- **Surnames come from the stored name.** Rosters keep names as *Last, First*,
  and the surname is read from that. A name entered the other way round is
  still handled, but an unusual compound surname may need a manual correction
  afterwards.
- **Existing pairing differences remain.** This release does not change the
  pairing algorithms or their deliberate differences from SwissSys.
- **Windows security prompts can still appear.** Signing does not override
  SmartScreen, antivirus policy or administrator permissions.

# FreePair v0.121.20260922

## What's new

- **Result-entry pages stop pulsing while you scroll.** TD result-entry pages no longer rebuild the board list when a background refresh only updates connection timing, so phones stay steady when the user is scrolled down.
- **NACH result entry is less fragile during brief network hiccups.** Hosted TD result entry now retries transient writer heartbeat failures while its lease is still valid instead of stopping locally on a one-off lost response.
- **NACH PIN is ready before sharing starts.** Checking **Enable Results Entering** prepares the NACH TD PIN immediately, so the TD can reveal, copy or change it before the public board goes live.

## Installer

- **Windows x64 release.** This is a Windows-only local release; macOS and Linux remain on the previous all-platform release until the next full-platform build.
- **Runtime and engines included.** The Windows installer bundles the required .NET runtime and pairing engines.

## Known limitations

- **Hosted pages still need the matching NACH update.** FreePair now avoids unnecessary local result-entry rebuilds and sends the hosted PIN earlier; NA Chess Hub should apply the same stable-refresh behavior on its hosted result-entry page.
- **Definitive hosted ownership loss still stops intake.** FreePair retries transient heartbeat failures, but rejected credentials, expired ownership and stale writers still require TD attention.

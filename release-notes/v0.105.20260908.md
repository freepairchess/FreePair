# FreePair v0.105.20260908

## What's new

### Signed Windows downloads

- **Windows downloads now carry a verified publisher signature.** The
  installer and packaged Windows executables are digitally signed as
  **Chessnique LLC** using Microsoft's Azure Artifact Signing service.
- **Timestamped signatures protect the release after signing.** Windows
  can verify the publisher and detect changes to signed files. Signatures
  are timestamped so they remain verifiable after the short-lived signing
  certificate expires, subject to normal certificate trust and revocation
  checks.
- **The tournament workflow is unchanged.** This release keeps the theme
  settings, labelled toolbar controls, pending-pairing display and pairing
  improvements from the previous Windows release.

## Installer

- **Windows x64 only for this release.** Run
  `FreePair-win-x64-Setup.exe` to install or update FreePair. The installer
  includes the .NET runtime, both pairing engines and the user guide.
  Keep your event backups as usual.
- **A signed portable download is also available.** The ZIP contains signed
  Windows executables; the ZIP itself is not an Authenticode-signed file.
- **Other desktop platforms remain on v0.103.20260906.** No new macOS or
  Linux packages are included in this release.

## Known limitations

- **Windows may still display security prompts.** Code signing establishes
  the verified publisher; it does not guarantee immediate SmartScreen
  reputation or override antivirus and organization security policies.
- **Signing does not change pairing behaviour.** Existing differences from
  SwissSys in some opponent choices, colours and board ordering remain.
  Agreement with another pairing program is not a rules verdict.

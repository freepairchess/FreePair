# FreePair v0.94.20260831

Windows release. macOS and Linux remain on `v0.90.20260829`.

A small follow-up to `v0.93`, all of it on the roster and the USCF
export.

## What's new

### Roster

- **The rating column is just "Rating" now.** It read *Rating
  [Pairing]*, which was answering a question nobody asks of the first
  rating column — the other one is already labelled Rating2. A section
  rated on the NWSRS scale still says **Rating [NWSRS]**, because there
  the label is naming a scale rather than restating the obvious: an
  NWSRS number and a US Chess number look identical in a grid and are
  not comparable.

- **Byes are labelled the short way.** The Kind column in **Byes &
  Withdrawals** now reads **HPB (½)**, **0-PB (0)** and **FPB (1)**,
  matching the **HPB** and **0-PB** columns on the roster itself. Spelled
  out as *Half-point bye* it was the widest thing in the panel while
  saying what you had just read in a four-character heading. The value in
  brackets is what the bye is worth on the scoresheet, so a bye can still
  be checked before it becomes a score.

  The same labels appear in **Byes this round** on the Pairings tab and
  in the popped-out byes window. Printed reports still spell the kind out
  in full — a sheet on a wall is read by people who do not have the rest
  of the screen for context.

### Filing the USCF rating report

- **The 🔎 beside a TD's ID opens the player database when the box is
  empty.** You are already at that button when you discover you do not
  know your assistant's USCF number, and being told *Enter a USCF ID
  first* is a dead end. It now opens the player database in your browser
  so you can find them by name and copy the ID back.

  The affiliate 🔎 deliberately does not do this: the player database
  holds players, and an affiliate code is not in there to be found.

- **The link and lookup buttons no longer overlap the ID box beside
  them.**

## Installer

Windows x64. The installer bundles the .NET runtime, so there is nothing
to install first. Run it and FreePair updates in place, keeping your
settings and recent-events list.

## Known limitations

**Platforms.** This release is Windows only. macOS and Linux are still on
`v0.90.20260829` and will be brought level on the next full release.

**Phone formatting is North American.** Seven, ten and eleven digit
numbers are regrouped for reading; anything else is shown exactly as it
was typed.

**Pairing fidelity.** FreePair's USCF engine is validated against a large
real-world SwissSys corpus and reproduces the great majority of pairings
exactly, reaching 100% on many representative events. The remaining
differences are in areas where the rules leave the director discretion —
board ordering within a score group, and which player takes a bye when
several are equally eligible — so both answers are legal.

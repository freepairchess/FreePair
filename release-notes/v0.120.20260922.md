# FreePair v0.120.20260922

## What's new

- **Cleaner phone result entry.** TD phones now scroll normally, show stacked board cards, and label boards clearly as `Board #2` instead of a bare number.
- **Better mobile result confirmation.** The confirmation page centers White, the chosen result, Black, and the action buttons in a phone-friendly order. Forfeit results stand out in red.
- **QR codes where phones need them.** Mobile result-entry, scoreboard, and PIN pages hide decorative logos and keep QR codes at the bottom of the page.
- **Scoreboard results stay readable.** The Result column reserves enough room for forfeits and draws, so values such as `0F - 1` and `0F - 0F` are no longer clipped.
- **Less disruptive information messages.** Routine confirmations, such as accepted tablet results, now appear as bottom-right toast messages that disappear automatically instead of pushing the workspace down.

## Installer

- **Windows x64 release.** This is a Windows-only local release; macOS and Linux remain on the previous all-platform release until the next full-platform build.
- **Runtime and engines included.** The Windows installer bundles the required .NET runtime and pairing engines.

## Known limitations

- **Hosted features require compatible NA Chess Hub support.** FreePair includes the local UX changes and a NACH implementation prompt; the hosted NACH pages must be updated separately.
- **Connection interruptions may need TD follow-up.** If a hosted result was not recorded in FreePair, the TD can enter it directly on the laptop.
- **Existing pairing trade-offs remain.** Established SwissSys-discretionary pairing differences are unchanged.

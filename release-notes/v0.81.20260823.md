# FreePair v0.81.20260823

The first release since **v0.77** to include **Linux and macOS** builds
again. If you are on either, this is the one to take — v0.78, v0.79 and
v0.80 were Windows-only, and your update check has had nothing to find
since v0.77.

Most of this release is team events and the screens a director actually
works in all day.

## What's new

### Team events

- **Whole-team roster actions.** Soft-delete, restore, permanently
  delete, withdraw, return and rename a team from the team roster —
  each applying to every player in the squad. Renaming a team moves all
  its players with it, which also fixes the registration typo that
  splits one squad into two: rename one onto the other and they merge.
- **Delete follows the same two-step as players.** A team can be
  soft-deleted (reversible) and only then permanently deleted, and only
  before round 1 is paired. After that the route is withdrawal, which
  keeps games already played on the record.
- **A withdrawn player is no longer given a board.** In a team match, a
  player who had withdrawn could still be handed a game — the round
  would go up with a board nobody was going to sit at, and a result
  waiting to be entered for someone who had gone home. Fixed.
- **An individual's requested bye no longer affects team pairing.**
  Teams are paired against teams and the captain picks the line-up, so a
  player's own bye is information for the captain rather than an
  instruction to the pairing engine. This was already how it behaved;
  it is now guaranteed.

### The wallboard in a team event

- **Team match-ups now go up on the screen** before the board pairings —
  match number, both teams with their seeds, and the board score as it
  stands. A running match shows its score part-finished, because that is
  what a room watches; a match nobody has finished shows a dash rather
  than 0–0, which would read as a set of draws.
- **Team standings too**, before the player standings: place, team,
  match points, board points. That is what the event is decided on.

### Focus mode

- **The focused table now fills the window.** That was the point of the
  mode and it was not doing it — a table kept whatever height it already
  had and left most of the screen empty.
- **A tab with two tables can focus either one.** The Roster tab always
  has two, and in a team event so do Pairings, Standings and Wall Chart.
  Each table has its own Focus button and fills the window alone.
- **The strip along the top says what you are looking at**, including
  the round on the Pairings tab — "Focus mode — Open — Round 3
  Pairings". Focus mode takes the round selector away with everything
  else, so that line is the only thing left telling you which round you
  are typing results into.

### Getting around

- **Byes & Withdrawals is now part of the Roster tab**, folded away at
  the top with its count in the heading, instead of a tab of its own. It
  is a short list you consult while working on the roster, and having it
  elsewhere meant leaving the roster to answer a question about the
  roster.
- **Pairing a round brings the pairings forward** in a team or
  round-robin section, as it already did for an individual Swiss.
- **Reopening an event returns you to the tab you left**, including
  which tab of the event area — it used to remember that you were in the
  event area but always open on Basic.

### Icons and text

- **The toolbar and the section tabs now draw their icons from one
  font.** They were coming from as many as four, which is why some
  looked heavier or sat lower than their neighbours; two of them were
  even being drawn by a maths font. Everything FreePair draws now ships
  inside the application, so the same icons appear on Windows, Linux and
  macOS.
- **Undo and redo lost the dark box behind them**, and the menu carets
  are drawn rather than typed, so they cannot change shape between
  platforms.

## Installer

Windows, Linux (x64) and macOS (Intel and Apple Silicon). The installer
bundles the .NET runtime and the pairing engine — there is nothing to
install first.

Updating from inside FreePair works again on Linux and macOS with this
release.

## Known limitations

- **Downgrading to an earlier version is not yet possible from inside
  the application.** If a release does not suit you, the previous
  installers remain on the releases page and can be run directly.
- **Updates download in full.** There are no incremental updates yet, so
  each one fetches the whole application.
- **The team bye button is not there yet.** A whole team can be
  withdrawn, but asking for a bye for every member in one step still has
  to be done player by player.
- **Linux and macOS builds have had less exercise than the Windows one**
  this cycle. The work is largely layout, fonts and keyboard handling —
  the areas most likely to differ between platforms. Please report
  anything that looks wrong rather than working around it.

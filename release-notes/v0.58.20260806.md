# FreePair v0.58

Your **display settings can now travel with an event**. Save a copy of an event
to the cloud, open it on a different computer, and FreePair can present it the
way you had it set up — same theme, same score style, same pairing columns. This
release also fixes **"Open recent…" closing the event you were working on**.

## What's new in v0.58

### Take your look and feel to another computer

- **Optionally save your display settings with the event.** The "save a copy to
  the cloud" prompt now has an *"Also save my display settings with this file"*
  checkbox. It is **off by default** and remembers your last choice, so nothing
  changes unless you ask for it.
- **What travels:** your theme, whether scores show as `1/2` or `½`, your
  pairing column choices for both the screen and the printed pairing sheet, your
  remembered search filters, and where your popped-out windows sit.
- **What never travels:** anything specific to a computer or to you — engine
  locations, your recent-files list, folder locations, account addresses, and
  your USCF director details are all left out on purpose.
- **Opening such a file asks first.** If an event carries display settings that
  differ from yours, FreePair asks whether to use them, defaulting to yes. Say
  no and nothing changes.
- **Your own preferences are never overwritten.** Using an event's display
  settings only changes how FreePair looks until you close it. Your saved
  preferences stay exactly as they were, and the next time you start FreePair
  everything is back to your setup. Change a display setting yourself while
  you're borrowing an event's look and your choice takes over and sticks, as
  usual.

### Fixes

- **"Open recent…" no longer closes the event you're working on.** Picking an
  event from the recent list now opens it in a **second FreePair window**, so you
  can run two events side by side — the same behaviour the regular Open command
  has always had.

## Known limitations

- **Display settings are carried only when you tick the box.** The option lives
  on the save-a-copy-to-cloud prompt and is off until you turn it on; events
  saved without it behave exactly as before.
- **Borrowed settings last for the session.** This is deliberate — another
  director's preferences should never quietly replace your own. If you want a
  look permanently, set it yourself in the Settings tab.
- **Pop-out window positions are approximate on a different screen setup.**
  Windows are always brought back onto a visible monitor, so a position saved on
  a three-monitor desk can't strand a window off-screen on a laptop.
- **Section roster columns were already event-specific** and continue to travel
  with every event file regardless of this option.

# FreePair v0.129.20260925

## What's new

- **Replacing an event file creates the new event cleanly.** When you save a newly created event over an existing `.sjson` and confirm replacement, FreePair writes a fresh event file instead of mixing in data from the old event. The old event's rounds, extra metadata and hosted-results journal do not carry into the replacement. Automatically chosen filenames still avoid overwriting existing files.

## Installer

- **Windows x64 release.** This update is Windows-only; macOS and Linux remain on the previous all-platform release.
- **Runtime and engines included.** The Windows installer bundles the required .NET runtime and pairing engines.

## Known limitations

- **Some discretionary choices can differ from SwissSys.** When the source event does not record a director's rationale for a legal board-order or bye choice, FreePair may make a different permitted choice.

# FreePair v0.131.20260928

## What's new

- **Roster and Pairings views are easier to tailor.** Use each grid's View menu to choose optional columns or restore its useful defaults. Roster ID and rating metadata controls now sit beside the roster, with secondary controls shown only when their matching columns are visible.
- **Late entries get smarter missed-round byes.** For rounds that already exist, FreePair assigns half-point byes up to the section's allowance, then zero-point byes. Directors can still edit the results manually.
- **Moved players are easier to spot.** Newly moved players stand out in the destination section so directors can review the roster change.
- **Rating refresh gives a clear review signal.** Unconfirmed zero ratings display an error-colored `!` beside the value, while confirmed unrated players keep the green check. A warning is shown without opening a separate results dialog.
- **Related sections keep their tie-break setup.** New sections created from an existing section, copied sections, and move destinations inherit its tie-break selection.
- **Imported event details and player slots stay consistent.** Web-event imports use the event page's title and time control; roster searches, edits, and rating refresh follow the section's ID and rating slot metadata.

## Installer

- **Windows x64 release.** This update is Windows-only; macOS and Linux remain on the previous all-platform release.
- **Runtime and engines included.** The Windows installer bundles the required .NET runtime and pairing engines.

## Known limitations

- **Some discretionary choices can differ from SwissSys.** When the source event does not record a director's rationale for a legal board-order or bye choice, FreePair may make a different permitted choice.

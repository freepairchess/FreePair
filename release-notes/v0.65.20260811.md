# FreePair v0.65.20260811

## What's new

### Printing

- **Printed sheets can fill the page.** Turn on *Fit the text to the page
  automatically* and FreePair picks the largest text size that still fits your
  round on one page, instead of leaving the bottom of the sheet empty. A
  typical round now prints noticeably larger than before.
- **Page setup, every time you print.** Clicking Print opens page setup for
  the report you are printing, so you can set the paper orientation, typeface,
  text size, row spacing and margin before the PDF is made. Each report keeps
  its own setup: a pairing sheet gets posted on a wall and written on by hand,
  so it wants big type and roomy rows, while a wall chart is a dense grid that
  has to fit a round per column.
- **Your page setup is remembered.** Set it once and every later print of that
  report uses it, on this computer and across restarts. The same settings live
  in the Settings tab if you would rather set them all up in one place.
- **The printed typeface is yours to choose.** Reports are no longer fixed to
  one font.

### On-screen text

- **Grid text size and typeface are adjustable**, with A− / A+ buttons and a
  font picker on every section tab, so you can enlarge the grids mid-event
  without leaving the tab you are working in.
- **Columns grow with the text**, so making the type bigger no longer clips
  the ends of names.
- **Font pickers show each font in its own typeface**, so you can see what you
  are choosing.

### Pairing columns

- **No more duplicated values on the pairing sheet.** If you show the combined
  White/Black Player column, it now takes over the separate rating, colour
  history and colour-due columns instead of printing the same values twice.
- **Hiding a column now hides it everywhere.** Unticking colour history or
  colour due removes it from the sheet entirely, including from inside the
  combined player cell where it used to remain.
- **The preview matches the result.** The sample rows in Advanced Options show
  exactly the columns and cell contents you will get on screen and on paper.

### Saving

- **A Save Event button** shows where your event file is, when it was last
  saved, and lets you rename it, save a copy, or save a backup copy to NA
  Chess Hub. FreePair still saves every change as you make it — this exists so
  you can see that, and see where.
- **Renaming never deletes anything.** The original file is left exactly as it
  was; it simply stops being updated.
- **Cloud backups confirm themselves**, and a failure says plainly that your
  local event is unaffected.

### Display settings that travel

- Your grid and print fonts are carried inside the event file along with the
  theme, score style and column layouts, so an event opened on another
  computer can look and print the same.

## Installer

Windows installer with the .NET runtime bundled — no separate install needed.
Existing installations update themselves.

## Known limitations

- **Automatic text fitting is a close estimate, not a guarantee.** It measures
  how much has to fit and leaves a margin for error, but an unusually long
  name can still wrap. If a sheet does not come out the way you want, turn the
  option off and set the size yourself.
- **Column widths are not remembered.** Widths you drag are reset when you
  leave a section and come back, and when you change the text size.
- **This release is Windows only.** macOS and Linux builds follow in the next
  full release.

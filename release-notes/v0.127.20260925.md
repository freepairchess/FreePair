# FreePair v0.127.20260925

## What's new

- **Move players works reliably in long events.** The dialog scrolls through the destination's past-round choices without covering the player list or action buttons, and it uses rounds that actually exist rather than a stale imported count.
- **Copying players no longer blocks hosted result updates.** A copied entry in another section now has its own hosted-results identity, while the source entry remains intact.
- **Result attribution is easier to read.** The Pairings columns now say **Results From** and **Results Who**.

## Installer

- **Windows x64 release.** This update is Windows-only; macOS and Linux remain on the previous all-platform release.
- **Runtime and engines included.** The Windows installer bundles the required .NET runtime and pairing engines.

## Known limitations

- **Some discretionary choices can differ from SwissSys.** When the source event does not record a director's rationale for a legal board-order or bye choice, FreePair may make a different permitted choice.

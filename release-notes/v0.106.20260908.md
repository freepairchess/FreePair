# FreePair v0.106.20260908

## What's new

### Clearer, recoverable messages

- **Action messages stay below the whole toolbar.** Information, warnings
  and errors appear in one full-width area beneath the event buttons,
  including Live Score Board, Share and Print. Identical status and warning
  text no longer appears twice.
- **Dismiss a message without losing it.** Open **Messages** to browse this
  window's session history, with timestamps and severity labels. **Show
  again** recalls a past message without repeating the operation or changing
  the event. Messages and history remain accessible in focus mode.
- **Partial rating results are warnings, not failed operations.** A refresh
  that confirms some ratings but cannot confirm others shows one warning.
  A refresh that cannot confirm any applicable ratings still shows an error.

### More reliable identity verification

- **A FIDE identity in ID2 is checked against FIDE first.** When it is the
  only national identity present, FreePair no longer starts with a US Chess
  lookup. A response identifying a different player ID is not accepted as
  confirmation.

## Installer

- **Windows x64 only for this release.** Run
  `FreePair-win-x64-Setup.exe` to install or update. The installer includes
  the .NET runtime, both pairing engines and the updated user guide.
- **Setup now uses the FreePair logo.** Windows packaging uses the same icon
  as the application, rather than the generic program icon.
- **Signed as Chessnique LLC.** The installer and packaged executables
  retain digitally signed, timestamped publisher identification. A portable
  ZIP containing signed executables is also available.
- **macOS and Linux remain on v0.103.20260906.** No new packages for those
  platforms are included here.

## Known limitations

- **Message history is session-only.** Closing the application window clears
  its history; messages are not saved into the tournament file.
- **Windows can still show security prompts.** Signing establishes the
  publisher but does not bypass SmartScreen reputation, antivirus rules or
  administrator-permission prompts. The logo alone is not proof of trust.
- **Some SwissSys pairing differences remain.** Opponent, bye and colour
  choices can differ in some situations. Agreement with another program is
  not a rules verdict; this release does not change the pairing algorithm.

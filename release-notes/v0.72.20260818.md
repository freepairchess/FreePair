# FreePair v0.72.20260818

## What's new

### Event setup

- **Event Configuration is now tabbed.** The page had grown into one long
  scroll; it is now **Basic**, **Team Event**, **Results Publishing** and
  **Starting Boards**. Everything still saves as you type, whichever tab
  you are on.
- **The organizer's name and ID moved to the Basic tab**, next to the
  event's other identifying details. They print on reports whether or not
  you ever publish results.
- **Team and match size have their own rows**, and the team board-order
  default now lives only on the Team Event tab instead of being duplicated
  in two places.

### Starting boards

- **New events just use the recommended board numbers.** FreePair works
  out each section's starting board from the sections before it and
  applies it — pairing no longer stops to ask, once per section, every
  round. Multi-section events stack cleanly with no setup at all.
- **A board you set yourself is never overruled.** Put a section in
  another room on board 40 and it stays on board 40 for the rest of the
  event. FreePair only fills in the blanks. If you prefer to be asked each
  round, turn off **Always use the recommended starting board** in
  Settings.
- **Starting boards set on an imported event now survive reopening.**
  Previously a board set on a section that came from a SwissSys file was
  quietly lost when the file was closed and opened again.
- **Choosing board 1 deliberately now sticks.** It used to be stored the
  same way as "never chosen", so the section could drift onto a different
  board later.

### Sync with NA Chess Hub

- **A bye requested after the round is paired is now reported.** It cannot
  be granted as asked — the pairings already exist — so it appears marked
  **Too late** with no Apply checkbox. The note tells you what the player
  actually got for that round, which is often not what they asked for: a
  player who requests a half-point bye after pairing may already have been
  given a full-point bye, or may have played a game. Your options are to
  delete the round and pair it again, or to let the player know their
  request came in late.
- **Byes you have already granted are not reported.** If the player asked
  for a half-point bye and got exactly that, there is nothing to tell you,
  even though the request may no longer show in the roster's HPB column
  once the round has been scored.
- **Bye requests for future rounds are no longer missed** when an event's
  round counter disagrees with the rounds actually paired, which could
  happen after publishing and then unpairing a round.

### Fixes

- **A section's Overview tab scrolls again.** On smaller screens the
  Starting Board and Danger Zone panels were cut off with no way to reach
  them.

## Installer

The Windows installer bundles the .NET runtime — nothing else to install.
Download and run it; FreePair updates itself from future releases.

## Known limitations

- **Windows only this release.** macOS and Linux builds are not part of
  this drop.
- **A late bye request keeps the sync badge lit.** There is nothing to
  apply that would clear it, by design — the count goes away when the
  request is withdrawn on NA Chess Hub. This was a deliberate choice: TDs
  said they would rather keep seeing it than have it disappear.
- **The tabbed configuration page has not yet been through a live event.**
  Note the Team Event tab stays mostly empty until **Team Event** is
  ticked; that is expected, not a fault.

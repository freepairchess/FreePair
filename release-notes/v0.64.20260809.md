# FreePair v0.64.20260809

Windows, macOS (Apple Silicon and Intel) and Linux.

## What's new

### Printing

- **Fewer clicks to get a sheet on the wall.** Printing a report no longer
  asks where to save it. The PDF goes straight into the event folder,
  alongside the tournament file, under a name derived from the section and
  the report, then opens in your PDF viewer ready to print. FreePair no
  longer pops open a file-browser window afterwards — the file is always in
  the event folder, so there is nothing to hunt for.

- **Reprinting asks before replacing.** If a PDF of that name already
  exists you get three choices: **Replace** it, **Save As…** under a
  different name, or **Cancel** the print entirely.

- **Pairing sheets are easier to read and write on.** Larger type, more
  space between rows, and darker table rules that survive printing and
  photocopying. The previous hairline rules were close to invisible on a
  printed sheet, which left the columns looking unseparated.

- **Two result columns instead of three.** The pairing sheet now prints one
  result box beside each player, the arrangement scorers expect. The third
  column, which sat between the White player and the Black pair number and
  belonged to neither side, is gone. Recorded results and bye points still
  print. Existing customised column layouts are updated automatically; the
  middle column can be re-ticked if you actually want it.

- **Page setup is remembered per report type**, so a pairing sheet and a
  wall chart can each keep their own font size, row spacing and
  orientation.

### FIDE pairing on macOS

- **FIDE (Dutch) pairing now works on every platform FreePair ships.**
  Previously the FIDE engine was unavailable on macOS because the upstream
  project publishes Windows and Linux binaries only. FreePair now builds the
  engine from source for macOS as a single package covering both Apple
  Silicon and Intel Macs. It is verified against the engine's own test suite
  before shipping, and produces the same pairings as the Windows and Linux
  builds across the full validation corpus.

### Fixes

- **No more phantom bye prompts.** After re-pairing, FreePair could offer
  to turn a requested half-point bye into a full point, and a paired-out
  player's full-point bye into a half — sometimes as two prompts stacked
  directly on top of each other. Nothing was actually proposing those
  changes; it was a display fault in the pairings grid. Changing a bye kind
  yourself still asks for confirmation, exactly as before.

## Installer

Each platform gets its native installer, with the .NET runtime bundled —
nothing else to install.

- **Windows:** `FreePair-win-x64-Setup.exe`
- **macOS:** `FreePair-osx-arm64-Setup.pkg` (Apple Silicon) or
  `FreePair-osx-x64-Setup.pkg` (Intel)
- **Linux:** `FreePair-linux-x64.AppImage`

Portable zips are attached for anyone who prefers not to install.

## Known limitations

- **FreePair is not code-signed or notarised.** Windows SmartScreen may warn
  on first run — choose "More info" then "Run anyway". macOS shows a
  Gatekeeper warning; open System Settings → Privacy & Security → Open
  Anyway. Note that macOS 15 removed the Control-click bypass.
- **The Apple Silicon build ships untested on Apple Silicon hardware.** The
  build machines are Intel, and Rosetta translates Intel code on ARM rather
  than the reverse, so the ARM half cannot be exercised there. It is built
  and signed the same way as the Intel half.
- **Printed pages do not yet auto-fit.** A short section still leaves white
  space at the bottom of the page rather than growing the type to fill it.
- **No settings screen for page setup yet.** The improved defaults apply
  automatically, but there is not yet a dialog for adjusting font size, row
  spacing or orientation by hand.
- **Only the pairing sheet has been tuned.** Every other report prints
  exactly as it did before.

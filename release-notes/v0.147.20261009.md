# FreePair v0.147.20261009

## What's new

- **Pairing sheets put the section first.** Printed headers keep the event name and a compact date range together, highlight the section name, and show time control on its own line. Dates do not repeat a shared month or year; missing time control leaves the line blank. One-page quad sheets center the quad and round above the boards, with start time at the far right. The Board column fits its contents rather than taking unused space.
- **Export PGN headers across the event.** Event Operations → Export Report → PGN headers lets you choose sections and individual paired rounds for one game-header file. The old section-only menu is gone; no moves or byes are written.
- **Cleaner separate windows.** Section pop-out buttons now say **Window**. Pairings, Standings and Wall Chart windows omit QR codes and the QR option; printed QR codes are unchanged.
- **Earlier rounds included in new scoreboards.** New events start with **Include Previous Rounds** selected, including events created from a registry seed. An explicit preference in an existing file remains unchanged.

## Installer

- **All four platforms.** Windows x64, Linux x64, macOS Apple silicon and macOS Intel builds are included.
- **Runtime and engines included.** Installers and portable builds bundle the required .NET runtime and pairing engine.

## Known limitations

- **Existing scoreboard choices are preserved.** Events created before this release without the preference saved are not retroactively changed.
- **Some discretionary choices can differ from SwissSys.** When a source event does not record why a legal board-order or bye choice was made, FreePair may make a different permitted choice.

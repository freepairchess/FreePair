# FreePair v0.126.20260924

## What's new

- **Events with external registration rosters can start in FreePair.** My Events on NA Chess Hub now includes events whose roster is not hosted on NACH. FreePair imports from the linked registration site when supported, and retains the event's NACH connection for pairing uploads and results entry.
- **Team results are entered board by board.** Team matches remain visible as matchups, while each game result belongs to its individual board. Local result-entry pages show team board labels such as 1.1 and 1.2, grouped in match-and-board order.
- **Team scoreboards are easier to follow.** The desktop and local network scoreboards list team boards in numeric match-and-board order, even when their underlying physical board numbers differ.
- **Pairing options fit more screens.** The Round 1 dialog wraps settings and scrolls vertically instead of requiring a horizontal scrollbar.

## Installer

- **Windows x64 release.** macOS and Linux remain on the previous all-platform release until the next full-platform build.
- **Runtime and engines included.** The Windows installer bundles the required .NET runtime and pairing engines.

## Known limitations

- **NACH-hosted board labels depend on NACH page support.** FreePair includes the optional `boardLabel` with hosted result snapshots, but the NACH page must render and sort by that field to show the same match-and-board labels. Numeric board/game identifiers remain unchanged for result routing.
- **Quick Windows release.** The full Core suite retains known baseline failures; focused tests cover the changed behavior.

# FreePair v0.51

A **team board-order** release that lets you control how each team's players are
assigned to boards (board 1, board 2, …) — either automatically by rating or by
hand for captain-declared line-ups. It also tidies up the team settings in the
Event configuration and the Roster tab. Nothing changes for ordinary individual
events, so upgrading is low-risk and recommended.

## What's new in v0.51

### Choose how teams are ordered onto boards

- **Automatic or Manual board order.** Every team section now has a **Team Board
  Order** policy. *Automatic* orders each team's boards by rating (board 1 =
  highest rated), breaking ties by player name (A–Z). *Manual* lets the team
  captain declare the order by hand — ideal for FIDE-Olympiad-style line-ups that
  don't strictly follow rating.
- **Set it at the event or the section level.** Pick a default on the Event
  configuration tab; every **new** team section inherits it. Existing sections
  keep their own setting — changing the event default never overwrites sections
  you've already created. Each section can be switched on its own Team Roster tab.
- **Edit a Manual line-up easily.** In Manual mode (before round 1 is paired), the
  Team Roster tab shows a single **Board Order** column where you can type a
  board number or nudge a player up/down with the ▲/▼ buttons.
- **Safe switch back to Automatic.** Switching a section from Manual to Automatic
  warns you first that hand-entered board numbers will be replaced by rating
  order, and lets you cancel.

### Clearer team setup

- **Confirm board order when you pair round 1.** The team pairing setup dialog now
  states plainly whether the section is Manual or Automatic (instead of a
  confusing checkbox), so you can confirm or cancel before the first pairing.
- **Dedicated Team Event Settings.** Team Event, Bughouse, team/match size, and
  the default board order now live in their own tidy card on the Event
  configuration tab.
- **New sections follow the event.** In a team (or bughouse) event, a freshly
  added section starts as a team section by default, inheriting the event's
  team/match size and board-order policy.

### Roster tab tidy-up

- **One toolbar at the top.** The Roster tab's actions (ID and Rating, Roster
  Update, Print, Optional Columns) now sit in a single menu bar at the top of the
  tab, matching every other tab.

rules-reference document — no additional downloads or configuration required.

## Known limitations

- **Board order is set before round 1.** Manual board reordering (typing numbers
  or the ▲/▼ buttons) is available until the section pairs its first round, after
  which the line-up is locked for the event.
- **SwissSys fidelity is unchanged.** The Swiss pairing engine and its regression
  coverage are exactly as in the previous version; the known divergences remain
  catalogued as deliberate future-work trade-offs.

# FreePair v0.69.20260813

## What's new

### A user guide that comes with the app

- **New Help button** in the top-right of the main window, next to the
  theme picker. **F1** opens it too. The guide covers running an event
  end to end: creating and opening events, sections, rosters and ratings,
  pairing rounds, byes and withdrawals, results and standings, printing,
  saving, NA Chess Hub, the rating report and settings.
- **It works with no internet.** The guide is installed alongside
  FreePair and opens in your browser straight from your own machine —
  which matters in a playing hall, where connections are least reliable
  and a question is most likely.
- **A contents panel down the left**, with sections you can collapse, so
  you can jump to what you need instead of scrolling.
- **The guide names the version it describes.** The copy installed with
  FreePair always documents the FreePair you are running, so it cannot
  quietly describe last month's software.

### The USCF rules reference now ships too

- **Rule citations open instantly and offline.** In the "Why this
  pairing?" dialog, clicking a rule now opens the rules reference
  installed with FreePair and jumps straight to that rule. Previously
  this needed a working internet connection.
- **Garbled characters are gone.** The rules document had been showing
  replacement characters where dashes, fractions and arrows belonged, in
  headings and throughout the text. Every one has been repaired, and the
  status markers in the coverage tables now read as plain words instead
  of question marks.
- **A rule link that went nowhere is fixed.** Citations for the
  lowest-rated player floating down — one of the most common
  explanations you will see — were landing at the top of the document
  instead of at the rule. They now land on the rule itself, and a build
  check makes sure no citation can go missing again.

### The Save event dialog fits on the screen

- **Nothing is cut off any more.** On smaller laptop screens the bottom
  of the Save event dialog — including the cloud backup section and the
  Close button — could be off the edge of the display with no way to
  reach it. The dialog now scrolls and can be resized, and **Close stays
  visible** whatever the window size.

## Installer

- Windows installer, single file. Bundles the .NET runtime and both
  pairing engines — nothing to install separately.
- The user guide and the USCF rules reference are installed with the
  app.
- Updates from an earlier version in place; your settings and recent
  events are kept.

## Known limitations

- **This release is Windows only.** macOS and Linux builds were not
  produced for this version; the previous cross-platform release remains
  available for those.
- **The user guide is complete in structure, uneven in depth.** Every
  area of the program has a section, and the wording matches what is on
  screen, but some topics — the rating report in particular — are
  currently brief. It will fill out release by release.
- **Offline rule and help links have been verified on Windows only.** On
  macOS and Linux they are expected to work but have not been confirmed
  on this release.

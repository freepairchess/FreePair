# FreePair v0.119.20260922

## What's new

- **Scoreboard and result entry together.** View the live scoreboard and switch to protected TD result entry from the same shared site, locally or through NA Chess Hub.
- **Separate TD PINs.** Local-network and NA Chess Hub result entry each have their own six-character PIN, with easy reveal, copy and change controls.
- **Safer online sharing.** Only one FreePair instance can share an event on NA Chess Hub at a time. Hosted results are saved locally before confirmation, and temporary connection problems no longer hold up closing the event.
- **Better phone and TV displays.** Responsive scoreboard pages, a visible countdown and adjustable page timing make shared displays easier to follow. QR cards offer simple copy/open links, with updated TV-streaming guidance.
- **Clearer result tracking.** The selected Where and By Who columns show result attribution even after sharing stops. Imported events and newly generated sections also retain the identities needed for hosted result entry.

## Installer

- **Runtime and engines included.** Installer packages bundle the required .NET runtime and pairing engines.
- **All four desktop platforms.** Windows x64, Linux x64, and macOS on Apple Silicon and Intel.

## Known limitations

- **Hosted features require compatible NA Chess Hub support.** This release provides TD-PIN entry; logged-in player self-entry is not included.
- **Connection interruptions may need TD follow-up.** If a hosted result was not recorded in FreePair, the TD can enter it directly on the laptop.
- **Existing pairing trade-offs remain.** Established SwissSys-discretionary pairing differences are unchanged.

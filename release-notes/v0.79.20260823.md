# FreePair v0.79.20260823

**A small Windows-only release.** Two corrections to focus mode, both
about a control saying what it will actually do. If you are on Linux or
macOS, see **Known limitations** below.

---

## What's new

- **The Focus button now says what pressing it will do.** It used to
  read "Focus (F11)" whether or not you were already in focus mode,
  which invited a second press and told you nothing. In focus mode it
  now reads **Exit Focus Mode (F11)**, and pressing it leaves.
- **Pairing a round brings its pairings to the front.** Press `F5` from
  the Roster, or use the Pair button beside a section, and the section
  now switches to its Pairings tab once the round is made. Previously
  you could pair a round and see nothing change, which is hard to tell
  apart from nothing having happened. If you were in focus mode you
  stay in it.

Nothing else is altered. This release changes two pieces of UI
behaviour and no pairing, scoring, reporting or file handling.

---

## Installer

- **Windows only.** The installer bundles the .NET runtime and both
  pairing engines; there is nothing to install alongside it.
- Updating from v0.78 changes no data and no settings. Your events are
  untouched.

---

## Known limitations

- **There is no Linux or macOS build in this release, as with v0.78.**
  If you run FreePair on either, stay on **v0.77.20260821** — it is the
  most recent release complete for all platforms, and no pairing,
  scoring, reporting or file behaviour has changed since. Automatic
  update checks on those platforms may report a failure until a full
  release is cut; that is this gap, not a fault in your installation.
- **This release has been exercised on Windows only.**
- Everything listed under **Known limitations** in v0.78 still applies.

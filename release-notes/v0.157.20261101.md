# FreePair v0.157.20261101

## What's new

### Side games and section management

- **Create a side-game section from full-point byes.** Sections → Full Point Bye Side Sections finds players awarded a full-point bye in each selected section's latest paired round, even when sections are on different rounds. Review the sections and name the new one-round roster; the original sections, byes and results remain unchanged. Arrange and pair the side games in the new section.
- **Clearer section actions.** Delete Pairing from NA Chess Hub and Publish Pairing to NA Chess Hub sit together at the end of both Pairing menus, with Publish last. The redundant projected-pairing refresh action is gone; Delete Pairings already preselects trailing rounds without results.

### Roster, standings and pairing review

- **Withdrawn players stay visible.** Roster and Standings show Withdrawn beside each affected name. The Pairings tab also accounts for withdrawn players who have no board or bye in the selected round, without duplicating players in historical rounds.
- **Byes remain visible after award.** Standings shows recorded half-, zero- and full-point byes alongside pending requests, including when a request was removed after pairing.
- **Filter the roster by state.** The new State field matches the complete state code, so searching for MA no longer includes players whose names happen to contain those letters. It works alongside the existing search and updates the player count.
- **More accurate confirmation and sync messages.** Deleting only unscored pairings no longer looks like discarding recorded results; deletions that lose results still show a red warning. Paired-round bye changes from NA Chess Hub appear as one informational note and do not overwrite recorded results. The ratings and ID-verification warnings name the operation that Cancel will skip.
- **Catch incomplete TD IDs before USCF export.** Chief TD and optional Assistant TD USCF member IDs must contain exactly eight digits before lookup, opening a profile link or creating the report.

## Installer

- **All four platforms.** Windows x64, Linux x64, macOS Apple silicon and macOS Intel builds are included.
- **Runtime and pairing engine included.** Installers and portable builds bundle the required .NET runtime and pairing engine.

## Known limitations

- **Side games need a director's pairing decision.** The new section copies eligible players but does not choose opponents, change the original results, or manage later side-game rounds automatically.
- **Already-paired bye changes still require review.** Roster sync reports those differences without changing the paired round. A TD can correct a recorded bye in Edit Player; automatic commitment-deadline enforcement requires information the Hub does not yet provide.
- **Linux account sign-in needs a credential keyring.** Install and unlock a Secret Service-compatible keyring to store NA Chess Hub credentials securely.
- **Some discretionary choices can differ from SwissSys.** When a source event does not record why a legal board-order or bye choice was made, FreePair may make a different permitted choice.

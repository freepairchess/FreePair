# FreePair v0.97.20260901

## Fixed

**Pairing a section as quads from its own button works again.** In
`v0.96` it failed immediately with *"Failed to pair as quads: Pairing in
progress…"* — the pairing was refusing to start because it had already
started. Every direct quad pairing was affected.

Pairing the same section through **Pair all sections** was never
affected, which is why the fault took a day to surface. If you hit this
during an event, that was the workaround; it is no longer needed.

The section's Pair-as-quads button is otherwise unchanged: it still
refuses, with the same message, if a pairing genuinely is already
running.

## Everything from v0.96 is still here

If you are coming from `v0.95` or earlier, `v0.97` also carries
everything in the `v0.96` notes — one coin toss for the whole event with
its own tab on the event page, the rewritten Delete Pairings dialog that
lets you choose which sections and rounds to clear, the keyboard shortcut
list moving to **Help → Keyboard Shortcuts**, and the "Signed in as …"
line on **My events on NA Chess Hub**.

## Installer

Windows x64. The installer bundles the .NET runtime, the pairing engines
and the user guide. Run it and FreePair updates itself in place; your
events and settings are untouched.

## Known limitations

- **Windows only in this release.** macOS and Linux remain on
  `v0.95.20260901` and will catch up on the next full run. The quad fault
  above does not affect them, because it was introduced after the version
  they are on.
- **A round cannot be deleted from the middle.** Player history is kept
  in order, so clearing round 2 necessarily clears round 3 as well —
  deliberate, since the alternative silently renumbers games that were
  played.
- **Keyboard shortcuts cannot be reassigned.**

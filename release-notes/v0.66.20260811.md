# FreePair v0.66.20260811 (Windows)

A usability release, driven almost entirely by feedback from directors
running FreePair on a small club laptop. Nothing about how pairings are
computed has changed.

## What's new

**Collapse the sidebar when you need the room.** The tournament sidebar
now folds down to a narrow strip of icons, keeping the event page and
every section one click away. It remembers your choice between sessions,
and the width you dragged it to comes back when you expand it again.

**Grid text and app text are now separate.** The A− / A+ control sits in
each grid's own header, next to that grid's filter, so you adjust the
text where you are reading it. Menus, tabs and dialogs have their own
size and typeface in Settings. Large pairing text with compact menus (or
the reverse) is now possible on a cramped screen.

**Go back to an earlier version of your event.** Before each big change —
pairing or deleting a round, importing players, deleting a section —
FreePair quietly saves a copy of your event file. **Save Event → Earlier
versions…** lists them: open one alongside your live event to compare, or
restore it. There is also **Undo** and **Redo** (Ctrl+Z / Ctrl+Y) for the
current session, which tell you what they are about to do before they do
it — "restore Round 1 of Open (6 pairings)", not just "undo".

**One less click on starting boards.** The starting-board prompt now
opens on the recommended number for a section's first round, so you can
just press Enter. If you would rather it never asked, there is a setting
for that — and it will still respect any board number you have set
yourself.

**A heads-up when sections share boards.** If two sections' board numbers
overlap, FreePair now says so — while you are typing the number, and on
the section's Overview tab. It never stops you: sections in different
rooms each having their own board 1 is perfectly normal, and the message
says as much.

**Set a section's starting board from the section itself.** It no longer
lives only on the event page. Change it in either place and the other
agrees straight away.

**Know where your event file is, and choose where it goes.** The events
folder setting now actually sticks (it was quietly resetting itself every
time you launched). Events downloaded from NA Chess Hub ask where to save
before writing anything, and Rename / Save a copy now open in the folder
your event already lives in, not one level up.

**Clearer publishing.** After publishing, the confirmation now names what
went up and when — "Published pairings and results to NA Chess Hub at
2:47 PM" — the button changes to "Publish again" instead of looking like
you still owe a step, and "Cancel" is now "Close", which is what it
always actually did.

**Switching sections no longer expands them.** Clicking through sections
to look at their rosters used to leave every one of them open, pushing
the rest off the bottom of the list. Sections now open and close only when
you ask them to, and the arrows point the same way as Expand all /
Collapse all.

## Installer

Windows installer, `FreePair-win-Setup.exe`. The .NET runtime and both
pairing engines are bundled — nothing else to install. Existing
installations update in place and keep your settings.

## Known limitations

- **Earlier versions are kept per event file**, in a folder beside it. If
  you rename an event, its earlier versions stay with the old name — they
  belong to the file they were taken from.
- **Undo covers this session only.** Closing FreePair clears it; that is
  what the saved earlier versions are for.
- **Going back does not un-publish or un-print.** Pairings already handed
  out or already sent to NA Chess Hub stay as they are until you publish
  again.
- **Restoring over your live event cannot itself be undone**, and the
  confirmation says so plainly before you do it.
- **App text scaling leaves small hint lines and headings at their own
  size**, so the layout keeps its structure rather than flattening to one
  size.

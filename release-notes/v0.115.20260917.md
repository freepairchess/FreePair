# FreePair v0.115.20260917

## What's new

- **QR codes say what they are for.** Printed and on-screen QR codes now carry purpose text inside the code image, so players can distinguish pairings, the Live Score Board, result entry and Wi-Fi at a glance.
- **Print QR Codes sheet.** The Print menu now has **Print QR Codes**, a one-page table of every currently available code with purpose text beside it. It can also include the venue Wi-Fi network and password on the same sheet.
- **Phone result entry is easier to use.** Result buttons are smaller, regular results are grouped in green, forfeits are separated in red, and every share-link row has its own **Open in browser** button.
- **NWSRS reporting handles new players better.** FreePair reads NWSRS school and grade from NA Chess Hub's explicit keys, keeps that data for players without an NWSRS ID, and exports a starter school+grade ID such as `TSTN` so the rating team can assign the full ID.
- **Roster and Pairings screens waste less space.** Sections without saved view state open on **Roster**, the noisy Status column is hidden by default, and a long **Byes this round** list no longer crushes the pairings table on laptop screens.

## Installer

- Windows x64 installer and portable package are published for this release.
- The installer bundles the required .NET desktop runtime and the pairing engines.

## Known limitations

- **Windows-only release.** macOS and Linux remain on the previous all-platform release until the next multi-platform build.
- **Known SwissSys-fidelity trade-offs remain.** The curated comparison suite still carries the established SwissSys-discretionary differences; this release focuses on TD workflow, QR sharing and NWSRS export improvements.

# FreePair v0.130.20260926

## What's new

- **QR-code print sheets use the page better.** One or two selected codes are larger and spaced down the page; three or four fill a two-row grid, with the third centered in the second row.
- **Merged sections keep hosted results compatible.** A section created after merging receives a unique saved ID, so hosted NACH setup is not blocked by the source section's retained ID.
- **NACH result-entry failures are clearer.** FreePair recognizes distinct sharing, disabled-entry, PIN reauthentication, incorrect-PIN and cooldown codes, and explains incomplete recovery data without guessing which result to acknowledge.
- **App exit is identified on the NACH release request.** FreePair adds an optional exit-reason header so a supporting NACH deployment can show that sharing has stopped.

## Installer

- **Windows x64 release.** This update is Windows-only; macOS and Linux remain on the previous all-platform release.
- **Runtime and engines included.** The Windows installer bundles the required .NET runtime and pairing engines.

## Known limitations

- **NACH must implement the matching hosted-result responses.** Distinct browser messages require NACH to return the requested stable error codes and to honor the optional `X-FreePair-Shutdown-Reason: application_exit` header. FreePair continues to release sharing using the existing endpoint contract if the header is ignored.
- **Some discretionary choices can differ from SwissSys.** When the source event does not record a director's rationale for a legal board-order or bye choice, FreePair may make a different permitted choice.

# FreePair v0.77.20260821

**Fixes FIDE pairing on Linux, which did not work at all on most
distributions.** If you run FreePair on Linux and pair FIDE sections,
please update.

---

## Please read this first

**FIDE pairing failed outright on most Linux machines.** Pressing pair on
a FIDE section produced an error mentioning `GLIBC` and no pairings at
all. It affected everyone except those on the very newest distributions:

| Distribution | FIDE pairing before this release |
|---|---|
| Ubuntu 22.04 LTS | **Failed** |
| Debian 12 | **Failed** |
| Linux Mint 21 | **Failed** |
| Red Hat / Rocky / Alma 9 | **Failed** |
| Ubuntu 24.04 LTS | Worked |

Nothing was damaged and no data was at risk — the pairing simply never
happened, visibly and immediately. USCF pairing was never affected, and
neither were Windows or macOS.

The bundled FIDE engine is now built so that it depends on nothing from
the host system. It runs on any 64-bit Linux regardless of age.

---

## What's new

### FIDE pairing on Linux

- **It works.** The FIDE engine no longer requires a recent system
  library, so pairing behaves the same on a five-year-old Linux install
  as on a brand-new one.
- **The pairings are unchanged.** The engine is built from the identical
  source revision used for macOS, and every release now verifies it
  against the engine authors' own test suite before shipping. A FIDE
  section pairs identically on Windows, Linux and macOS.

### Icons look the same everywhere

- **The delete and edit icons are clearer on Windows.** FreePair was
  letting each operating system supply its own version of each symbol,
  and Windows chose a thin, hard-to-read wastebasket. Every platform now
  uses the same icons, drawn from the fonts bundled with the app.
- **Colour coding is protected.** The reversible delete stays green and
  the permanent delete stays red. That distinction is now enforced
  automatically, so a future change cannot quietly turn those two
  buttons into the same thing.

---

## Installer

- **Windows, Linux and macOS.** The installer bundles the .NET runtime
  and both pairing engines; there is nothing to install alongside it.
- Updating from v0.76 changes no data and no settings. Your events are
  untouched.

---

## Known limitations

- **Icon shape can vary slightly between platforms.** Each system draws
  text at its own weight and spacing. The icons themselves are now
  identical everywhere; only the surrounding rendering differs.
- **The macOS FIDE engine is still built for both Apple Silicon and
  Intel, but only the Intel half is exercised automatically**, because
  the build machines are Intel. Both halves come from one compiler run,
  so a difference is unlikely, but it is stated rather than implied.
- Everything listed under **Known limitations** in v0.75 still applies.
  This release changes the Linux engine and the icons only; no pairing
  logic, scoring, reporting or file behaviour is altered.

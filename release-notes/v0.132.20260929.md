# FreePair v0.132.20260929

## What's new

- **NACH sharing recovers cleanly when a run is retired.** FreePair stops retrying the expired run and explains how to start a fresh share. Check the Pairings grid for results that may not have been recorded before restarting.
- **Windows stays awake during live sharing.** Automatic system sleep is inhibited while NA Chess Hub sharing is active, so the scoreboard and result entry can stay available. The display may still turn off; explicit Sleep and lid-close power settings can still interrupt sharing.
- **Dismiss soft-delete warnings.** Hide the section warning without restoring it. The section remains locked and excluded from publishing; restore or permanently delete it later from the Sections list.

## Installer

- **Windows x64 release.** macOS and Linux remain on the previous all-platform release.
- **Runtime and engines included.** The installer bundles the required .NET runtime and pairing engines.

## Known limitations

- **Automatic sleep inhibition is Windows-only.** It uses battery power and does not override an explicit Sleep command or lid-close power setting.
- **Some discretionary choices can differ from SwissSys.** When the source event does not record a director's rationale for a legal board-order or bye choice, FreePair may make a different permitted choice.

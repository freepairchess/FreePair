# FreePair v0.161.20261110

## What's new

### NA Chess Hub scoreboard PINs

- **Prepare tagged PINs before sharing.** For a saved Hub event, label the first scoreboard results-entry PIN and add more tagged PINs before the scoreboard goes live. Each PIN has its own identity and tag.
- **Manage PINs while sharing continues.** Add PINs, edit tags, revoke PINs or change a PIN without stopping the scoreboard. Changing a PIN revokes its previous identity and creates a new one under the same tag; past results retain their original attribution. Legacy single-PIN controls also remain usable during sharing.

### Roster

- **Verify IDs and refresh ratings from the roster header.** The new buttons beside the ID and Rating selectors run the same actions, review dialogs and warnings as the ID and Rating menu.

## Installer

- **Windows x64 only.** This release contains a signed Windows installer and portable build. Linux and macOS users can continue using the previous release.
- **Runtime and pairing engine included.** The Windows build bundles the required .NET runtime and chess pairing engine.

## Known limitations

- **Tagged PINs require a compatible NA Chess Hub server.** If the server does not support tagged PINs, a locally edited set of tagged assignments cannot start hosted results entry; FreePair will not silently combine distinct PINs into a single credential. An untouched event can still use the legacy single PIN.
- **Some discretionary choices can differ from SwissSys.** When a source event does not record why a legal board-order or bye choice was made, FreePair may make a different permitted choice.

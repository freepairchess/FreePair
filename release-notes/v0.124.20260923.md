# FreePair v0.124.20260923

## What's new

- **Hosted NACH result entry is less fragile.** FreePair now retries transient private NACH API failures while the public sharing session is still active, instead of stopping hosted TD intake for recoverable service hiccups.
- **Stopping hosted entry is explicit.** When TD result entry is stopped, FreePair tells NACH that entry is disabled before releasing its writer so the NACH page can show a clear stopped message rather than an incorrect-PIN or generic error.
- **The NACH TD PIN stays simple.** FreePair owns the PIN. It keeps the same NACH PIN across hosted stop/start, changes it only when the TD clicks **Change PIN**, and no longer recognizes any NACH-side request to force a PIN change.

## Installer

- **Windows x64 release.** This is a Windows-only local release; macOS and Linux remain on the previous all-platform release until the next full-platform build.
- **Runtime and engines included.** The Windows installer bundles the required .NET runtime and pairing engines.

## Known limitations

- **Quick Windows release.** This release uses the requested local Windows path with lengthy test gates skipped. Focused checks covered the changed hosted NACH result-entry and help-document paths.
- **NACH hosted-page behavior depends on deployment.** NACH should treat FreePair's disabled configuration as "FreePair stopped taking results" and should not force TD PIN changes.

# FreePair v0.114.20260913

## What's new

### Enter results from an iPad or phone

- **Players can enter results on the same Wi-Fi as FreePair.** Open **Share**, choose **Start result entry**, and scan its QR code. No NA Chess Hub account or internet connection is needed.
- **A simple score-table screen.** Large section and round tiles lead to a scrolling pairing list. Only the **Tap to enter result** button between the players opens entry, so touching names while scrolling does not open a dialog. Recorded scores appear in large type between the players; green checks identify completed boards, rounds, and sections.
- **Clear result confirmation.** Choose a win, draw, or forfeit, then review a large score and a short winner/draw message before confirming. An optional masked TD PIN protects submissions. The page includes the event logo and its own QR code for other players to scan.
- **Quads and round robins work across the whole schedule.** Unrecorded games in any paired round can be submitted, even when all rounds were paired in advance. Recorded games remain locked to players; corrections and byes stay with the TD.
- **Results return to FreePair and the event file.** The desktop pairing row updates, and the phone receives success only after saving. Changed pairings and duplicate submissions are rejected rather than overwriting a result. Save errors ask the player to contact the TD.
- **Sharing stays under the TD's control.** Start and stop result entry independently of the read-only Live Score Board. Closing or switching the event stops entry, and restarting gives a new QR link. PIN guessing is rate-limited.

### Shorter names when splitting quads

- **Name the generated quads before pairing.** The naming dialog defaults to **Quads {x}**, producing **Quads 1**, **Quads 2**, and so on. Customize the template and see a preview.
- **Parent names are optional.** **Include parent section name** starts off. The leftover group defaults to **Mini Swiss**; the same checkbox adds the parent name to it. Existing names are protected by collision-safe suffixes.
- **The same choices apply throughout FreePair.** Direct quad pairing, round-one preparation, and **Pair All Sections** use the naming choices. A single four-player section keeps its existing name.

### Safer desktop actions while players submit

- **An outdated Undo or Redo confirmation does not discard a newly entered result.** FreePair asks the TD to review the changed event instead.
- **Renaming an event keeps results entered during the save.** The destination receives the latest event state before becoming the active file.

## Installer

- **Windows x64, Linux x64, and macOS Intel and Apple Silicon packages.** Choose the download for your platform. The desktop packages include the .NET runtime, pairing engines, and updated user guide. Keep normal event backups before updating.
- **Windows installers and packaged executables are signed as Chessnique LLC.** Operating-system security policies may still display prompts.
- **Linux and macOS also receive the recent desktop improvements.** These include optional round-one preparation, event-level online settings, and clearer forfeit colour history that first shipped in the recent Windows releases.

## Known limitations

- **Trusted local networks only.** Result entry uses unencrypted HTTP. A shared PIN is not player identity: anyone with the link and PIN, if configured, can submit an eligible board. Internet result entry through NA Chess Hub is not included.
- **Guest Wi-Fi may block device-to-device access.** Phones must be able to reach the laptop; private-network firewall permissions, client isolation, and laptop sleep can prevent access. FreePair does not change router or firewall settings.
- **Team and bughouse results remain TD-entered.** The local player-entry page supports individual boards in supported sections; corrections and byes stay on the desktop.
- **Existing pairing differences remain.** This release retains the deliberate SwissSys comparison differences; it does not change the Swiss pairing algorithms.
- **Apple Silicon packages are cross-built.** CI cannot substitute for running the package on an actual Apple Silicon Mac.

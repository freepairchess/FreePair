# FreePair v0.125.20260924

## What's new

- **Player details are easier to find.** Add and Edit now separate pairing essentials, bye requests, affiliation and contact, and USCF, FIDE, CFC, and NWSRS data into tabs. USCF membership expiration and post-event ratings are grouped with the other USCF details.
- **Player search fills in more roster data.** Search results include NWSRS details, and choosing a result populates the available federation fields in the player form.
- **Roster columns are easier to manage.** Dismiss a column from its header to hide it and update the grid's saved display options. Double-clicking a roster value opens the player editor on the tab for that field.
- **Round progress is clearer.** Expanded and collapsed section summaries show the current unfinished round. Pre-paired Quads and round robins advance from round 1 to round 2 as results come in, with a green check on the final completed round.
- **Quad splits keep the rating choice.** Generated Quad and Mini Swiss sections inherit the parent's USCF post-event pairing-rating setting.

## Installer

- **Windows x64 release.** macOS and Linux remain on the previous all-platform release until the next full-platform build.
- **Runtime and engines included.** The Windows installer bundles the required .NET runtime and pairing engines.

## Known limitations

- **Quick Windows release.** The full Core test gate remains skipped because the v0.124 baseline already had 31 failures. The current run has 26 failures, all present in that baseline; 95 focused App/Core tests and the Release solution build passed.

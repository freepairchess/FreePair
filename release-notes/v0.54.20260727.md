# FreePair v0.54

A **file-attribution** update. The tournament files FreePair writes now
identify FreePair as the program that produced them, matching the same
`Program` / `Version` labelling that desktop pairing software has always
stamped into its files. This makes exported events self-describing for
NA Chess Hub and anyone inspecting the files. Upgrading is low-risk and
recommended.

## What's new in v0.54

### FreePair now signs its own files

- **Saved event files are labelled "Free Pair".** When you save an event,
  FreePair writes its program name and version into the file's overview
  section. An event that started life in another program is re-labelled as
  a FreePair file the first time you save it here.
- **Published results carry the same label.** The results file uploaded to
  NA Chess Hub also includes the FreePair program name and version, so the
  origin of a published event is unambiguous.

The installer bundles the .NET 10 runtime, the pairing engines, and the
rules-reference document — no additional downloads or configuration required.

## Known limitations

- **Existing files keep their original label until re-saved.** A file created
  by another program only shows the FreePair label after you save it in
  FreePair at least once.

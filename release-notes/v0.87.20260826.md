# FreePair v0.87.20260826

**Windows only.** If you are on Linux or macOS, **stay on
v0.86.20260826** — it has a build for your platform and this one does
not. Your update check may report a failure until the next release that
covers every platform.

A small release, and all of it is the two dialogs you use to open an
event. Both were showing you less than they had, and both now use the
whole screen.

## What's new

### The online-events list fits on the screen

Picking a cloud-saved event meant reading a table that did not fit its
window: a scrollbar along the bottom, and everything past the middle cut
off mid-word — a city showing as "Framinghan", a date as "8/26/202", a
club as "Metrowest Ch".

- **Every column is now sized to what is actually in it**, so dates,
  cities, zip codes and organisers read in full.
- **The event ID column is gone.** It was the widest column in the
  table and showed a long code with no meaning to anyone reading it —
  FreePair passes it along for you when you pick an event. If you need
  it, the event name still links to its page.
- **The button on each row now says "Download and Open"** instead of
  repeating "Download Cloud Saved Event File and Open" thirteen times
  down the screen. It does exactly what it did before.

### Both open-event windows start maximized

**Open a Cloud-Saved Event** and **Open recent tournament** now open
full-screen. Both are lists whose only job is to show you as many rows
as your screen can hold, and both were being resized by hand every time.
Un-maximize and you get the old window size back.

## Installer

`FreePair-win-x64-Setup.exe` is a single-file installer for Windows x64.
It bundles the .NET runtime and the FIDE pairing engine, so there is
nothing to install first. It adds a Start Menu entry and an uninstaller,
and updates itself from this feed. A portable zip is attached for anyone
who prefers not to install.

## Known limitations

**Platforms**

- **Windows only.** v0.86 covered Windows, Linux and both kinds of Mac;
  this one does not, because it was built on a Windows machine. Linux
  and macOS users should stay on v0.86 — nothing in this release affects
  pairing, results or files, so there is nothing to miss.
- **FreePair is not code-signed or notarised.** Windows SmartScreen may
  warn on first run — choose "More info" then "Run anyway".

**Files**

- **Nothing about your events changed in this release.** The file format
  is untouched, so a file saved by this version is identical to one saved
  by v0.85 or v0.86, and you can move between those builds freely.

**The online-events list**

- **A very long event name is shortened with an ellipsis** rather than
  being allowed to squeeze the other columns. The full name is on the
  event's own page, which the name links to.
- **Copying an event ID from the list is no longer possible**, since the
  column was removed. Nothing in FreePair needs you to do that; if you
  used it for something, say so and it can come back somewhere that
  costs no space.

# FreePair v0.134.20261002

## What's new

- **Teammate avoidance carries into mini-Swiss sections.** When a quad section is split and teammate avoidance is enabled, the leftover mini-Swiss also avoids pairing teammates for its three rounds.
- **Cloud copies can show who saved them and when.** When signed in, FreePair sends the displayed NA Chess Hub account name with a cloud-copy save; the cloud event list is ready to show the name and server-recorded save time. NA Chess Hub must support the new optional metadata before these details appear. Uploads still require the event passcode and work without sign-in.
- **Roster reviews can show when a registration was last edited.** A new **Last edited on NACH** column displays the registration's latest edit time when NA Chess Hub supplies it; otherwise it says **Not available**. This is not necessarily the time of the particular bye or check-in change on that row.

## Installer

- **Windows x64 release.** macOS and Linux remain on the previous all-platform release.
- **Runtime and engines included.** The installer bundles the required .NET runtime and pairing engines.

## Known limitations

- **New NA Chess Hub metadata depends on server support.** Older responses have no cloud-save provenance or registration edit times; FreePair continues to work without them. The saved-by name is client-reported display information, not verified identity.
- **Some discretionary choices can differ from SwissSys.** When the source event does not record a director's rationale for a legal board-order or bye choice, FreePair may make a different permitted choice.

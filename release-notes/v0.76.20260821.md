# FreePair v0.76.20260821

**Every button icon now draws correctly on Linux and macOS.**

If you run FreePair on Linux or a Mac, the toolbars, the section list and
the Players grid were rows of small empty rectangles instead of icons.
Windows was never affected. This release fixes it.

---

## What's new

### Icons on Linux and macOS

- **The icons are there now.** Edit, copy, delete, restore, withdraw,
  pair-next-round, move-players, open-folder, the seeding arrows and the
  check-in ticks all draw on every platform. Previously each one was a
  narrow vertical box — the "missing character" mark a font draws when it
  has nothing to show.

- **The fonts travel with the app.** FreePair no longer assumes the
  machine has a particular font installed. The faces it needs for symbols
  and pictographs are bundled inside the program, so a fresh Linux
  install with no extra fonts renders the same as a fully-loaded Windows
  desktop. Windows keeps using its own system fonts, so nothing looks
  different there.

- **Why it took a release to notice.** FreePair is developed on Windows,
  where the icons always worked, and the missing pieces are only visible
  on a machine that lacks Microsoft's fonts. The previous release was the
  first in a while built for Windows, Linux and macOS together, which is
  what put the problem in front of someone who could see it.

### The first-run note about pairing engines

- **Wider, shorter, easier to read.** The note explaining FreePair's two
  pairing engines was a narrow column of dense text in which the FIDE and
  USCF entries ran together. It is now wider, the two engines are clearly
  separate, and every sentence has been tightened. Nothing was removed
  that a director needs — when the engine locks, that either engine's
  crosstable is accepted for US Chess rating submission, and where to
  change it are all still there.

- As before, tick **Don't show this again** to retire it, and
  **Settings → Pairing engines** brings it back.

---

## Installer

- **Windows, Linux and macOS**, as with the previous release. The
  installer bundles the .NET runtime and both pairing engines, so there
  is nothing to install alongside it.
- The bundled fonts add roughly 4 MB to the download.
- Updating from v0.75 changes no data and no settings. Your events are
  untouched.

---

## Known limitations

- **The icons are standard symbols, not a custom icon set.** They are
  drawn from the same well-known character set on every platform, which
  is what makes them portable. They will not match the exact house style
  of Windows 11's own icons — this is the trade FreePair makes so that a
  director on any operating system sees a working button rather than an
  empty box.
- **Icon shape can vary slightly between platforms.** Each system draws
  these characters in its own house style where it has them. The meaning
  and position are identical everywhere; the exact curve of an arrow may
  not be.
- Everything listed under **Known limitations** in v0.75 still applies.
  This release changes appearance only — no pairing, scoring, reporting
  or file behaviour is altered.

# FreePair v0.163.20261116

## What's new

### NA Chess Hub links and publishing

- **New installs use the `www` Hub address.** The default publishing URL is now `https://www.nachesshub.com`. An address you previously saved, including `nachesshub.com` or a Hub staging subdomain, stays as you set it.
- **Event links stay on the selected Hub.** Published pairings, event pages, roster links, sharing previews and report QR codes use the host chosen for that event instead of switching between the bare and `www` hosts.
- **Mistyped destinations are rejected.** Settings and publishing accept only HTTPS URLs on `nachesshub.com` or its subdomains. A URL on another domain cannot receive an event upload.

## Installer

- **All four platforms.** Windows x64, Linux x64, macOS Apple silicon and macOS Intel builds are included.
- **Runtime and pairing engine included.** Installers and portable builds bundle the required .NET runtime and chess pairing engine.

## Known limitations

- **Browser sign-in is separate from FreePair sign-in.** Links open in the computer's default browser and profile. If that profile is signed out of the selected Hub host, the page can appear signed out even when FreePair is signed in; this release does not establish a browser session.
- **Some discretionary choices can differ from SwissSys.** When a source event does not record why a legal board-order or bye choice was made, FreePair may make a different permitted choice.

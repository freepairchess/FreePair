# FreePair v0.137.20261004

## What's new

- **More complete standings on NA Chess Hub.** Published standings now show each player's distinct standings number and tied place, plus a result column for every paired round. Round cells use the same readable win, draw, loss, bye, forfeit, color and pending notation as FreePair. Corrections and cleared results refresh the published board.
- **Simpler scoreboard sharing.** The Share window now presents NA Chess Hub as the scoreboard-sharing option. Local-network sharing controls are hidden; the underlying feature has not been removed.
- **Pairings windows open with byes.** Opening Pairings in a separate window no longer crashes when a round contains a bye. The bye message appears beside the player, with no game result in that row.

## Installer

- **Windows x64 release.** macOS and Linux remain on the previous all-platform release.
- **Runtime and engines included.** The installer bundles the required .NET runtime and pairing engines.

## Known limitations

- **NA Chess Hub sharing requires internet.** The local-network sharing controls are not available in the Share window.
- **Some discretionary choices can differ from SwissSys.** When the source event does not record a director's rationale for a legal board-order or bye choice, FreePair may make a different permitted choice.

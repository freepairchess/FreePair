# FreePair v0.140.20261006

## What's new

- **Both games stay visible on the shared scoreboard.** Double Swiss and double round-robin pairing pages now carry encounter and game numbers so a compatible NA Chess Hub can group color-swapped games and show their combined result. Each physical game retains its own boards, colors, byes and per-game result; a return game later in the schedule keeps its real round number. Unpaired or withdrawn return games do not appear.
- **Start with the game in play.** After pairing all sections, opening a Double Swiss section shows game 1 while it is still being played instead of jumping straight to game 2. Once game 1 is complete, game 2 opens by default. Choosing a round manually still works as before.

## Installer

- **All four platforms.** Windows x64, Linux x64, macOS Apple silicon and macOS Intel builds are included.
- **Runtime and pairing engines included.** Installers and portable builds bundle the required .NET runtime and pairing engine.

## Known limitations

- **Hosted encounter grouping depends on NA Chess Hub.** FreePair sends the public metadata; the NA Chess Hub page must support grouping to display combined encounter scores. This does not change results entry permissions or scoring.
- **Some discretionary choices can differ from SwissSys.** When a source event does not record why a legal board-order or bye choice was made, FreePair may make a different permitted choice.

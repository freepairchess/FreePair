# FreePair v0.62.20260809

## What's new

### FIDE pairing now works on macOS

- **Mac users get FIDE (Dutch) pairings.** Until now the macOS builds shipped
  without the FIDE pairing engine, and a TD who tried to pair a FIDE-rated
  section was told it was unavailable on their platform. That limitation is
  gone: macOS installers now bundle the engine, exactly as the Windows and
  Linux builds always have.

- **Nothing to install or configure.** The engine ships inside the app. There
  is no download step, no Settings path to point at, and no difference in how
  you pair a FIDE section compared with Windows or Linux.

- **Works on both Intel and Apple Silicon Macs from a single download.** The
  bundled engine contains native code for both processor families, so the same
  installer is correct whichever Mac you have.

- **Same engine, same pairings.** macOS runs the identical engine version as
  the other platforms (BBP Pairings v6.0.0), and the build is verified against
  the engine project's own pairing test suite before it is allowed to ship. A
  FIDE section paired on a Mac produces the same pairings it would on Windows.

## Installer

- macOS: `FreePair-osx-arm64-Setup.pkg` (Apple Silicon) or
  `FreePair-osx-x64-Setup.pkg` (Intel). Portable zips are also available if you
  prefer not to run an installer.
- Windows: `FreePair-win-x64-Setup.exe`. Linux: `FreePair-linux-x64.AppImage`.
- The .NET runtime is bundled on every platform — there is nothing to install
  first.

## Known limitations

- **Apple Silicon Macs: the FIDE engine is included but has not been run on
  Apple Silicon hardware by us.** Our build machines are Intel, and an Intel
  machine cannot execute Apple Silicon code, so that half of the engine is
  compiled and shipped without a live test. Both halves are produced from the
  same source in the same build step, so we expect no difference — but if you
  are on an M-series Mac, please report anything odd when pairing a FIDE
  section. Intel Macs are tested on every build.

- **Notarisation.** FreePair is not yet notarised with Apple, so macOS may warn
  on first launch depending on how you obtained the download. This is unchanged
  from previous releases.

- **USCF pairing is unaffected on every platform.** It has always been built
  into FreePair itself rather than provided by an external engine, and it
  continues to work everywhere.

# FreePair v0.78.20260822

**A Windows-only release.** Linux and macOS builds are not included this
time — if you run FreePair on either, stay on v0.77.20260821 and see
**Known limitations** below.

This one is about the main window. The screen gave up a row of chrome,
the toolbar adapts to the width you actually have, and everything you do
repeatedly during a round now has a key.

---

## What's new

### More room for the table

- **The tab strip is gone.** FreePair opened with two tabs, one of which
  held everything and the other of which was Settings. Both rows above
  your pairings have been reclaimed: the event fills the window, and
  Settings opens in a window of its own from **⚙ Settings** at the top
  right.
- **The toolbar adapts.** On a narrow screen it drops the button labels
  and keeps the icons, rather than wrapping onto a second row — because
  that second row comes straight out of the pairing grid, on exactly the
  laptops that have least to spare. Hover any icon and the tooltip names
  it. Widen the window and the labels come back.
- **Focus mode.** Press **F11**, or the **Focus (F11)** button on any
  table's header, and the toolbar, section list, tabs and setup controls
  all disappear so the table has the whole window. **Esc** brings them
  back. It is built for the moment you are working down a pile of
  scoresheets, and it is available on every tab except Overview.

### Keyboard shortcuts

- **The operations you repeat during a round now have keys** — pair the
  next round, pair every ready section, check the event, print, publish,
  sync rosters, open the wallboard. Every key is printed beside its menu
  item, so you can pick them up without going looking.
- **A full reference card lives in ⚙ Settings → Shortcuts**, which
  matters in a playing hall with no internet.
- Only the operations performed several times an hour got a key.
  Merging sections and filing rating reports stay one click away in the
  menu, because a shortcut list long enough to scroll is one nobody
  learns.

### Printing and output

- **A printer button sits in the toolbar**, with the four whole-event
  reports — pairings, standings, wall charts, crosstables — one press
  away instead of three levels into a menu.
- **Event Operations is shorter**, grouped into Print, Popup Windows and
  Export Report.
- **The FIDE rating report and TRF export no longer need a section
  selected first.** Both open a list of every section with its rating
  type and round status, and tick the ones that are plausibly what you
  meant — FIDE-rated sections with all results in.

### Themes and appearance

- **Picking a theme now recolours the whole application**, not just the
  buttons and highlights. The change is deliberately faint: that surface
  sits behind every piece of text you read, so it should be obvious when
  you switch and invisible while you work.
- **Icons are drawn from one set of bundled fonts**, so a row of buttons
  looks like a row of buttons rather than a collection from different
  places.

### The user guide

- **It has a search box.** Type, and the contents narrow to the sections
  that match, with every hit highlighted. Enter steps through them.
- **A new chapter on working alongside SwissSys** — what travels in each
  direction, and what does not.

## Installer

- **Windows only this time.** The installer bundles the .NET runtime and
  both pairing engines; there is nothing to install alongside it.
- Updating from v0.77 changes no data and no settings. Your events are
  untouched.

---

## Known limitations

- **There is no Linux or macOS build in this release.** If you run
  FreePair on either, stay on **v0.77.20260821** — it is complete for all
  platforms and none of the pairing, scoring or reporting behaviour has
  changed since. Automatic update checks on those platforms may report a
  failure until the next full release; that is this gap, not a fault in
  your installation.
- **This release has been exercised on Windows only.** Everything in it
  is layout, fonts, keyboard input and theming — the areas most likely
  to differ between operating systems — which is the reason the other
  platforms are held back rather than shipped unverified.
- **Keyboard shortcuts cannot be reassigned.** The list is fixed; see
  ⚙ Settings → Shortcuts.
- **Focus mode is not remembered between sessions.** It is a posture for
  a few minutes at the scoring table, not a preference, and finding the
  toolbar missing the next morning would be alarming rather than
  helpful.
- Everything listed under **Known limitations** in v0.77 still applies.
  No pairing logic, scoring, reporting or file behaviour is altered by
  this release.

# FreePair v0.152.20261016

## What's new

- **Roster and prize windows.** View → Popup Windows now opens rosters and prizes for selected sections in separate, read-only windows that update as the event changes. Section tabs no longer repeat Window controls, leaving more room for tournament work.
- **Choose PDF columns.** Page setup → Columns lets you choose which fields appear when printing the roster, standings, wall chart and prizes. Prize tables have their own column choices. Your PDF selections are saved, and existing layouts remain the default until you change them.
- **Clearer cloud backup and section actions.** The backup button now says “Save a copy to NA Chess Hub.” The Sections, Renumber Boards and Merge Sections actions have easier-to-recognize icons.

## Installer

- **All four platforms.** Windows x64, Linux x64, macOS Apple silicon and macOS Intel builds are included.
- **Runtime and engines included.** Installers and portable builds bundle the required .NET runtime and pairing engine.

## Known limitations

- **PDF column choices do not rearrange the on-screen grids.** The new selections apply only to printed reports; the separate roster and prize windows are read-only.
- **Some discretionary choices can differ from SwissSys.** When a source event does not record why a legal board-order or bye choice was made, FreePair may make a different permitted choice.

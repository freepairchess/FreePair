# FreePair v0.55

A small **follow-up to v0.54's file attribution**. The version FreePair
records inside the files it writes now shows the **actual FreePair version**
(for example `0.55.20260727`) instead of a placeholder. Upgrading is low-risk
and recommended.

## What's new in v0.55

### File attribution now shows the real version

- **Saved event files record the true FreePair version.** When you save an
  event, the version FreePair stamps into the file's overview section now
  matches the version you're running, rather than a fixed placeholder value.
- **Published results carry the same real version.** The results file uploaded
  to NA Chess Hub also records the running FreePair version, so it's clear
  exactly which build produced a published event.
- **Older SwissSys files still open cleanly.** Files created by SwissSys (whose
  version is stored as a number) continue to load without issue.

## Installer

- **Download:** [FreePair-win-x64-Setup.exe](https://github.com/freepairchess/FreePair/releases/latest/download/FreePair-win-x64-Setup.exe)
- **Portable zip:** [FreePair-win-x64-Portable.zip](https://github.com/freepairchess/FreePair/releases/latest/download/FreePair-win-x64-Portable.zip)
- **Auto-update:** Existing FreePair installs will pick up v0.55 automatically.
  To update now, click "Check for updates" in the Settings tab.

The installer bundles the .NET 10 runtime, the pairing engines, and the
rules-reference document — no additional downloads or configuration required.

## Known limitations

- **Existing files keep their recorded version until re-saved.** A file only
  shows the current FreePair version after you save it in this build at least
  once.

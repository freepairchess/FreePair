# FreePair v0.82.20260823

**Windows only.** If you are on Linux or macOS, stay on **v0.81.20260823**
— this release has no build for you, and your update check will have
nothing to find until the next one that does.

One feature, and it is the one that matters when something else goes
wrong: you can now go back to an earlier version of FreePair from inside
the application.

## What's new

### Going back to an earlier version

- **Every published release is now listed, not just newer ones.**
  **⚙ Settings → Updates → Change version** shows the full list for your
  platform and installs any of it. Until now, updating was a one-way
  door: if a release did not suit you, the way back was to find an old
  installer on the releases page — on a hall laptop, between rounds.
- **FreePair remembers the versions you have run**, and marks them with
  the date you last used them. After an update goes wrong, "the version
  I had yesterday" is the only way most people can name the build they
  want, and nothing was recording it. The list fills up as you go, so it
  starts being useful from your next update onwards.
- **A version you once ran that has since been withdrawn is still
  listed**, marked as no longer available, rather than quietly left out.
  A list missing the one thing you are looking for reads as broken.
- **Going back asks you to confirm, and says why.** An older FreePair may
  not understand an event file a newer one has saved: anything the newer
  version added can be ignored, or lost, the next time the older one
  writes the file. Copy your event file before going back, especially
  part-way through an event. Moving forward again asks nothing extra.

## Installer

Windows only this time. The installer bundles the .NET runtime and the
pairing engine — there is nothing to install first.

## Known limitations

- **Linux and macOS are not in this release.** Stay on v0.81.20260823.
  Updating from inside FreePair will report that it cannot find an
  update until the next release that carries builds for your platform.
- **Going back is judged on your event file by you, not by FreePair.**
  The application warns you, but it does not yet inspect the file to
  decide whether an older build can safely open it. Keep a copy.
- **Updates download in full.** There are no incremental updates yet, so
  each one — forwards or backwards — fetches the whole application.
- **The team bye button is not there yet.** A whole team can be
  withdrawn, but asking for a bye for every member in one step still has
  to be done player by player.

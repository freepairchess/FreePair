# FreePair v0.73.20260818

## What's new

### Knowing when the roster changes

- **FreePair can now make a sound when the sync count changes.** Turn on
  **Play a sound when the count changes** under
  **Settings → Online → Alert when NA Chess Hub roster has updates to
  sync**. Useful when you are heads-down on pairings and not watching the
  badge. It uses your computer's own notification sound, so it follows
  the system volume and Do Not Disturb, and it stays quiet when your own
  sync clears the count. Off until you turn it on.
- **A Test button** next to it plays the sound straight away, so you can
  check it is audible before relying on it.

### Opening events from NA Chess Hub

- **The Passcode label is now a link.** On the create-from-registry and
  open-cloud-event dialogs, once you have entered the Event ID the
  **Passcode** caption links to that event's page, where the passcode is
  shown. Click it and copy the passcode from there instead of hunting
  through email.

### Deleting a round

- **The confirmation is much harder to walk into by accident.** It is
  red, **Cancel** is the default button and sits on the right where your
  cursor lands, and the button that goes ahead is red.
- **It tells you what you are about to lose.** If results have already
  been entered for that round, the warning says how many, and that they
  will have to be typed in again from the score sheets.
- It also now says a checkpoint is taken first, so the round can be
  recovered from **Earlier versions** — the old wording claimed the
  delete could not be undone, which was not true.

### Pairing sheets

- **Choose the printed columns from Page setup.** When the report is the
  pairing sheet, a **Columns…** button opens a picker for the printed
  sheet alone, with a live preview of the row you will get. The full
  chooser is still on **Pairing Operations → Advanced options** if you
  want the on-screen grid and the printed sheet side by side.
- **FreePair now explains the result columns.** On screen the
  **Result / Score Selector** is what you enter results with. On paper
  the two **write-in** boxes are what the scorer fills in by hand, and
  the selector is left off because on a blank sheet it prints an empty
  third result column belonging to neither side. Change one of those
  three against the recommendation and FreePair says why and asks you to
  confirm. Every other column is a matter of taste and is never
  questioned.
- **Copy from grid no longer spoils the score sheet.** It used to copy
  the result columns too, which pulled the on-screen selector onto the
  printed sheet and removed the write-in boxes. It now copies the
  arrangement and leaves the result columns as they are.
- **A column change made in Page setup now reaches the printed sheet.**
  Previously it was saved but the sheet kept printing the earlier
  columns until the app was restarted.

### Elsewhere

- **Sync Roster with NACH** is now on the **Pairing Operations** menu as
  well as the Roster tab, since checking for late entries is usually the
  step just before pairing.
- The Page setup window is wider, so its buttons are no longer clipped.

## Installer

The Windows installer bundles the .NET runtime — nothing else to install.
Download and run it; FreePair updates itself from future releases.

## Known limitations

- **Windows only this release.** macOS and Linux builds are not part of
  this drop. The alert sound is implemented for all three, but only the
  Windows path has been exercised.
- **The alert sound needs a working audio device.** If the Test button is
  silent, check the system volume and Do Not Disturb; FreePair uses your
  computer's own notification sound rather than one of its own.
- **Most of this release's interface work has not yet been through a
  live event.** It is covered by tests and by review, but a club night is
  the real check.

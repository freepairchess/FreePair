# FreePair v0.89.20260828

A polish release. Nothing about pairing, scoring or reporting changed —
this one is about the tables you stare at all day being easier to read,
and about a handful of places where something was laid out where you
could not get at it.

> **Windows only.** This release carries the Windows build. If you are
> on macOS or Linux, stay on **v0.88.20260827** — it is the current
> release for your platform and nothing in this one changes how an event
> is paired or scored.

## What's new

### The tables are easier to read

- **Striped rows everywhere.** Every grid in the app — roster,
  pairings, standings, wall chart, byes, prizes — now alternates a
  faint row tint so your eye can follow a long row across to the far
  column without losing its place. The tint is tuned separately for the
  light and dark themes.
- **Column headers stand out.** Headers are bold, sit on a tinted
  surface and are separated from the first row by a rule, so the top of
  a scrolled table no longer reads as just another row.
- **Tables meet the edge of their card.** Section tables used to sit
  inside two nested frames, one gap apart, which drew a faint pair of
  vertical lines down the empty area beside the rows. There is now a
  single frame, and the table uses the full width of its panel.

### Pairing options split in two

The one crowded **Advanced** dialog on the Pairings tab is now two:

- **Advanced Pairing Options** — the settings that belong to *this
  section* and lock once round 1 is paired.
- **Display and Print Columns** — which columns you want to see and
  print, which is a preference that follows *you*, not the event. It
  opens maximized, so the full list of columns is in front of you
  instead of behind a scrollbar.

Splitting them also makes it obvious why one of them stops accepting
changes mid-event and the other never does.

### Five new keyboard shortcuts

| | |
|---|---|
| **Ctrl+Shift+T** | Print every round-robin and quad crosstable |
| **Ctrl+Shift+R** | New event from an online registry |
| **Ctrl+Shift+W** | New event from a published web address |
| **Ctrl+Shift+H** | My events on NA Chess Hub (start a new one) |
| **Ctrl+Shift+V** | My events saved on NA Chess Hub (re-open one) |

The full list is always under **Help → Keyboard Shortcuts**.

### Byes

- **Double-click any row in a Byes table** — on the Roster tab or in
  *Byes this round* on the Pairings tab — to open that player straight
  on their **Byes** tab, ready to change their requests. Double-click
  rather than single, deliberately: moving through a list with the
  arrow keys changes the selected row, and a single click would have
  thrown a dialog in your face while you were reading down the column.
- **The byes table now sits under its own heading** when the board
  pairings above it are collapsed, instead of floating down the middle
  of the empty space.

### Prizes

- **Print includes the prize projection** when the event is still
  running and prizes have not been calculated yet — so the printout
  shows who is currently in line for what, rather than an empty page.
- **Each prize table scrolls on its own**, so a long prize list no
  longer runs off the bottom of its panel with no way to reach the rest.
- **The Prizes tab scrolls like every other tab** — one scrollbar, in
  the table, instead of the whole page moving.

### Elsewhere

- **Collapsing one panel gives its space to the other.** On tabs with
  two tables, collapsing the top one now lets the bottom one grow into
  the space instead of leaving a gap.
- **Help → About FreePair** shows the FreePair icon, and the pairing
  fidelity tool that ships alongside now carries it too.

## Installer

Windows x64. The installer bundles the .NET runtime and the bbpPairings
engine — there is nothing else to install. Existing installations
update in place and keep your settings, recent events and NA Chess Hub
sign-in.

## Known limitations

- **This release is Windows only.** macOS and Linux remain on
  v0.88.20260827.
- **The roster's counting column stays left-aligned.** Right- or
  centre-aligning the `#` header is not reachable through the theme
  without the header and its rows disagreeing by a few pixels, which
  looks worse than the alignment it fixes.
- **Pairing fidelity is unchanged from v0.88.** The engine was not
  touched in this release.

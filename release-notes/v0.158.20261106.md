# FreePair v0.158.20261106

## What's new

### NA Chess Hub sign-in and membership

- **Choose your account when you log in.** Clicking Log in opens NA Chess Hub's sign-in page instead of silently reusing an account already signed in through the browser. Log in as a different user still switches accounts, and FreePair can still restore a saved sign-in at startup.
- **Understand entitlement problems.** Account status now identifies whether an entitlement failed its signing-key, signature, account, membership, or timing check without displaying the token or account ID. A clock-related reason points you to the computer's date and time; an active membership alone cannot bypass a failed verification.

### Saving and roster updates

- **Recover from brief file-access conflicts.** FreePair retries transient Windows access-denied or sharing failures when saving or loading an event file, including the save required before acknowledging hosted results. A persistent failure is still reported; a missing event file is never silently recreated.
- **Find recent roster changes first.** Sync Changes shows the latest NA Chess Hub edits first. You can sort by the actual date and by numeric ratings in the detail column; applying selected changes keeps their original processing order.

## Installer

- **Windows x64 only.** This release contains a signed Windows installer and portable build. Linux and macOS users can continue using the previous release.
- **Runtime and pairing engine included.** The Windows build bundles the required .NET runtime and chess pairing engine.

## Known limitations

- **Membership verification still depends on NA Chess Hub.** An invalid signed entitlement cannot be used even if an account reports an active membership. Account status now gives a more specific reason to help diagnose the problem.
- **Persistent file-access errors still need attention.** Retry covers short-lived access conflicts, not permissions that remain denied or files that have been removed.
- **Some discretionary choices can differ from SwissSys.** When a source event does not record why a legal board-order or bye choice was made, FreePair may make a different permitted choice.

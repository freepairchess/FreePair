# FreePair v0.123.20260922

## What's new

- **Results can be put back in play.** If a TD records a game too early, the local result-entry page now lets them unlock the board and choose **Game still in play** so the result can be entered later.
- **NACH corrections can also clear a result.** NACH result entry can send a still-in-play correction back to FreePair without stopping hosted intake.
- **Cleaner result-entry board list.** The mobile scoring page now uses a **Game filter** dropdown for **All Games**, **Games with Results**, and **Games in Play**, with a smarter default that focuses on unfinished games.
- **Sharing controls stay usable.** NACH and local PIN reveal/copy controls remain available while sharing is starting or running, and the share dialog button heights are now consistent.
- **Hosted sharing is more resilient.** FreePair keeps the NACH hosted entry session alive across transient sharing-session recovery cases instead of stopping TD result entry unnecessarily.

## Installer

- **Windows x64 release.** This is a Windows-only local release; macOS and Linux remain on the previous all-platform release until the next full-platform build.
- **Runtime and engines included.** The Windows installer bundles the required .NET runtime and pairing engines.

## Known limitations

- **Quick Windows release.** This release uses the requested local Windows path with lengthy test gates skipped; focused checks covered the changed result-entry and NACH paths.
- **Hosted page styling depends on NACH deployment.** FreePair now accepts and applies the still-in-play correction from NACH; the NACH-hosted browser page must expose the matching button in its own deployment.

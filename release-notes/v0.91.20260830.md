# FreePair v0.91.20260830

A small fix release on top of v0.90, for Windows.

## What's fixed

**Column headers in Standings and Wall Chart were missing a dividing
line.** One column in each table had no vertical rule between its header
and the next, so the header row looked broken in a way the rest of the
table did not. Which column it happened to be depended on how the
column widths worked out, which is why it moved around and why it looked
different on the two tabs.

The tables themselves are unchanged — only the missing divider is back.

## Installer

The installer bundles everything FreePair needs, including the .NET
runtime and both pairing engines. There is nothing to install separately.
Existing installations update in place from **Settings → Updates**.

## Known limitations

Unchanged from v0.90.

- **This is a Windows-only build.** macOS and Linux stay on v0.90, which
  is otherwise identical; the fix is cosmetic and no data or pairing
  behaviour differs between them.
- **A small number of SwissSys-fidelity differences remain** in board
  ordering and in bye choices that SwissSys makes at the director's
  discretion. These are known, tracked, and do not affect the legality of
  a pairing.

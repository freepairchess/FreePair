# FreePair v0.104.20260908

## What's new

### Clearer tournament controls

- **Theme selection is now in Settings > Display.** All palettes remain
  available, apply immediately and save automatically. Moving the selector
  out of the main toolbar leaves more room for tournament commands.
- **Live Score Board, Share and Print have visible labels.** Share now uses
  the familiar three-connected-dots symbol instead of a television icon.
  On narrow windows the toolbar still switches to icons with tooltips.

### See a round's pairings before it finishes

- **Standings and Wall Chart can show pending pairings.** The new
  **Show pending pairings** checkbox is on by default. A code such as
  `?7B` means Black against opponent 7 in a paired but incomplete round;
  it is not a result or an awarded point.
- **One choice controls both player tables.** Turning the checkbox off hides
  pending entries without hiding completed results or future requested byes.
  Separate windows and PDFs printed from these section tabs follow the same
  choice. It is remembered for that section during the current session.
- **Scores are not changed by this display option.** Standings continue to
  use completed rounds. When the whole round finishes, pending game codes
  become result codes; deleting its pairings removes the pending entries.
  In Standings, opponent numbers refer to standings rows; in Wall Chart,
  they refer to pairing numbers.

### More consistent USCF pairing decisions

- **Colour improvements respect the floater rating limits.** FreePair no
  longer sends a much higher-rated player to a lower score group solely to
  improve colours when that substitution exceeds the applicable rating
  limit. Necessary changes to avoid rematches or pairing constraints remain
  distinct from optional colour improvements.
- **A floater's actual opponent matters.** When a rematch prevents the
  expected matchup, FreePair can compare complete legal alternatives within
  the rating limits instead of accepting avoidable colour problems.
- **Earlier colour history breaks otherwise equal ties.** FreePair now
  checks the latest round where the players' colours differed, and the
  pairing explanation identifies that round.
- **Dedicated regression coverage protects the improvements.** Approved
  round-by-round pairings, colours and byes are retained as automated guards,
  alongside the existing SwissSys comparison corpus.

## Installer

- **Windows x64 only for this release.** The installer bundles the .NET
  runtime, both pairing engines and the user guide. Install it over your
  existing FreePair installation; keep your event backups as usual.
- **Other desktop platforms remain on v0.103.20260906.** This release does
  not include new macOS or Linux packages.
- **Authored release notes are included again.** This release page and the
  mirrored notes file contain the explanations above, rather than only an
  automatically generated comparison link.

## Known limitations

- **Pending-pairing visibility is a session preference.** It resets to on
  when the event is reopened. It controls the player tables and their
  section-tab PDFs; whole-event reports and the Live Score Board retain
  their existing display behaviour.
- **Partially entered rounds still appear as pending in these tables.**
  Individual game results remain available on Pairings while Standings
  waits for the round to finish.
- **SwissSys agreement is not a rules verdict.** Some opponent choices,
  colours and board ordering still differ. Do not treat a matching
  percentage as proof that every possible pairing situation is covered.
- **Earlier release notes are not retroactively restored.** The missing
  authored notes on the v0.103 page are a separate publishing-content issue;
  the release link itself is correct.

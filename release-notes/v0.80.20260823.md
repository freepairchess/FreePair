# FreePair v0.80.20260823

**A Windows-only release.** Two new features and several corrections. If
you are on Linux or macOS, see **Known limitations** below.

---

## What's new

### An event reopens where you left it

FreePair now remembers which section and which tab you were on, and puts
you back there when you open the event again. No navigating to the same
place after every lunch break.

It is remembered **in the event file**, so it follows the event — open it
on the machine at the other end of the table and it is showing the same
round.

**Reading an event does not change it.** The view is written only when
you actually moved somewhere. Open an event, look something up, close it
again, and the file is untouched — its contents and its timestamp both.
If the section you were on has since been renamed, merged or deleted,
the event simply opens as normal.

### Crash reports

If FreePair ever closes unexpectedly it now writes a report describing
what went wrong. **⚙ Settings → Updates** says how many there are and
when the most recent was, with a button to open the folder.

**A report contains no event data at all** — no player names, no
ratings, no contact details, no results. It has the error, the FreePair
version, your operating system, and the file name of whichever event was
open. FreePair never sends it anywhere; whether it leaves your computer
is entirely your decision. Attaching the most recent one to a bug report
is the single most useful thing you can do. The twenty newest are kept.

### Installing updates

- **You can now install an update from ⚙ Settings → Updates.** Press
  **Check now**, and if there is one an **Install update and restart**
  button appears beside the result — useful if you dismissed the banner,
  or came to this page to deal with updates in the first place.

### Smaller things

- **The round picker's tick and hourglass follow your theme**, so they
  stay legible on the dark themes instead of being a fixed green and
  amber.
- **The Focus button now says what pressing it will do** — it reads
  **Exit Focus Mode (F11)** once you are in focus mode.
- **Pairing a round brings its pairings to the front.** Press `F5` from
  the Roster and the section switches to Pairings once the round is
  made, rather than leaving you looking at an unchanged screen.

---

## Installer

- **Windows only.** The installer bundles the .NET runtime and both
  pairing engines; there is nothing to install alongside it.
- Updating from v0.79 changes no data and no settings. Your events are
  untouched.
- Event files gain one small entry recording your last view, the first
  time you navigate in them. It is ignored by SwissSys and removed
  automatically from rating submissions.

---

## Known limitations

- **There is no Linux or macOS build in this release, as with v0.78 and
  v0.79.** If you run FreePair on either, stay on **v0.77.20260821** —
  the most recent release complete for all platforms. No pairing,
  scoring, reporting or file behaviour has changed since. Automatic
  update checks on those platforms may report a failure until a full
  release is cut; that is this gap, not a fault in your installation.
- **This release has been exercised on Windows only.**
- **The last view is remembered per event, not per computer.** Two
  directors sharing an event file will each land where the other last
  was. It is a convenience, not a setting, and costs nothing to ignore.
- **Toolbar icons are still a mix of filled and outlined designs.** They
  come from a bundled icon font whose glyphs are drawn inconsistently.
  Making them uniform means drawing them rather than picking characters,
  which is a deliberate piece of work rather than a quick fix.
- Everything listed under **Known limitations** in v0.79 still applies.

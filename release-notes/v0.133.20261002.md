# FreePair v0.133.20261002

## What's new

- **Correct hosted results safely.** TDs can correct a result entered through NA Chess Hub, including returning a game to **Game still in play**. FreePair saves the change before acknowledging it to the hosted page.
- **Sharing recovers automatically.** Temporary NA Chess Hub outages are retried without stopping the share. If the hosted run is retired or replaced, FreePair rebuilds the scoreboard and result-entry page from the locally saved event; scores already saved in FreePair are retained. Results that reached only the hosted page may need to be re-entered.
- **Result entry is on by default.** Uncheck **Enable Results Entering** before starting if you want a read-only scoreboard. Connecting and publishing the first scoreboard is shown as information; recovery attempts remain warnings.
- **Fewer writes while sharing is idle.** Heartbeats and unchanged scoreboard refreshes no longer repeatedly save the event file. Actual result and configuration changes still save as needed.
- **Easier PIN setup and support.** Set or generate a separate hosted TD PIN. Local diagnostics help investigate connection problems without recording event credentials, PINs, or player results.

## Installer

- **Windows x64 release.** macOS and Linux remain on the previous all-platform release.
- **Runtime and engines included.** The installer bundles the required .NET runtime and pairing engines.

## Known limitations

- **Unsaved hosted results cannot be reconstructed.** If a hosted result never reached FreePair before a server reset, re-enter it after sharing recovers. FreePair remains the source of truth for saved results.
- **Some discretionary choices can differ from SwissSys.** When the source event does not record a director's rationale for a legal board-order or bye choice, FreePair may make a different permitted choice.

# FreePair v0.162.20261110

## What's new

### Pairing every section

- **More room to review sections on smaller screens.** Pair All Sections keeps its section table usable at higher display scaling. The batch settings start open on larger displays and collapsed on shorter ones; expand the full-width, theme-coloured header to see every option without a separate settings scrollbar. On narrow screens, scroll the table sideways to inspect the remaining columns with their headings.

### NA Chess Hub scoreboard PINs and roster

- **Tagged scoreboard PINs now available on every platform.** Prepare labelled results-entry PINs before sharing a saved Hub event. While sharing, add PINs, edit tags, revoke PINs or change a PIN without stopping the scoreboard; past results retain their original attribution.
- **Verify IDs and refresh ratings from the roster header.** The buttons beside the ID and Rating selectors open the same review flows as the corresponding menus.

## Installer

- **All four platforms.** Windows x64, Linux x64, macOS Apple silicon and macOS Intel builds are included.
- **Runtime and pairing engine included.** Installers and portable builds bundle the required .NET runtime and chess pairing engine.

## Known limitations

- **Tagged PINs require a compatible NA Chess Hub server.** If the server does not support tagged PINs, locally edited tagged assignments cannot start hosted results entry; FreePair will not silently combine distinct PINs. An untouched event can still use the legacy single PIN.
- **Some discretionary choices can differ from SwissSys.** When a source event does not record why a legal board-order or bye choice was made, FreePair may make a different permitted choice.

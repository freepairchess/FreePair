# FreePair v0.117.20260920

## What's new

- **Safer ID and rating slot controls.** FreePair now understands the newer
  NA Chess Hub section-level labels for `ID`, `ID2`, `Rating`, and `Rating2`,
  and backfills them from older row-level labels when available. Plain
  SwissSys files stay blank until IDs/ratings are verified, so a director
  cannot accidentally relabel unknown columns.
- **Roster columns update from the right source.** On rich NA Chess Hub
  exports, changing a section's ID or rating slot can project from the stored
  USCF, FIDE, CFC, or NWSRS values already carried on each player row. Empty
  `ID2`/`Rating2` controls are hidden unless there is real secondary data, or
  enough rich NA Chess Hub data to create the secondary columns safely.
- **USCF post-event pairing ratings refresh cleanly.** When a section pairs on
  USCF post-event/current ratings, Refresh Ratings now includes the post-event
  pull in the progress dialog and marks the active Rating column with the green
  confirmation check after the post-event value is applied.
- **Round 1 pairing stays in the director's control.** The round-1 flow no
  longer silently runs ID verification, rating refresh, or NA Chess Hub roster
  sync. It shows reminders and settings first, including the same path for
  direct quad pairing.
- **NA Chess Hub roster sync is less noisy.** Rating-difference reports were
  removed from roster sync. Roster sync still handles real roster, bye, and
  check-in changes.
- **Roster and event polish.** Fresh roster layouts hide Email and Phone by
  default, the close-event cloud-copy prompt now defaults to **Skip and
  close**, and duplicate-open diagnostics try to name the owning FreePair
  window/process when the same event file is already open.

## Installer

- Windows x64 installer and portable zip are published for this release.
- The installer bundles the required .NET desktop runtime.
- macOS and Linux builds remain on the previous all-platform release until the
  next full-platform build.

## Known limitations

- **Windows-only release.** This release updates Windows x64 only. macOS and
  Linux users should keep using the latest all-platform build.
- **SwissSys compatibility is intentionally conservative.** Files that do not
  say what an ID or rating column contains require verification before FreePair
  will let the director repurpose that column.
- **Rating refresh still depends on federation services.** If US Chess, FIDE,
  or NWSRS lookups are unavailable, FreePair preserves the stored values and
  reports what could not be confirmed.
